# 第三章 栈、队列和数组
## 3.1 栈
### 3.1.1    栈的基本概念
- ①. 栈的定义

  - 栈(Stack)是只允许在一端进行插入或删除操作的线性表
    - 栈顶(Top): 允许进行插入和删除操作的那一端
    - 栈底(Bottom): 固定的，不允许进行插入和删除操作的另一端
    - 空栈: 不含任何元素的空表
  - 操作特性: 后进先出(LIFO)

- ②. 栈的基本操作

  - InitStack(&S): 初始化一个空栈S
  - StackEmpty(S): 判断栈是否为空
  - Push(&S,x): 入栈操作
  - Pop(&S,&x): 出栈操作
  - GetTop(S,&x): 读栈顶元素
  - DestroyStack(&S): 销毁栈

- ③. 栈的数学性质

  - n个不同元素入栈时，出栈元素不同排列的个数为卡特兰数(Catalan)公式


### 3.1.2   栈的顺序存储结构
- 栈的定义

  - 操作受限的线性表
  - 两种存储方式
    - 顺序存储
    - 链式存储

- ①. 顺序栈的实现

  - 定义
    - 采用顺序存储的栈
    - 一组地址连续的存储单元存放数据元素
    - 附设栈顶指针(top)指示当前栈顶位置
  - 存储类型描述
    - #define MaxSize 50 // 顺序栈大小
    - typedef struct{}SqStack; // 对象定义
    - Elemtype data[MaxSize]; // 顺序栈
    - int top; // 栈顶指针
  - 栈顶指针操作
    - 初始设置
      - S.top = -1
      - 栈顶元素：S.data[S.top]
    - 入栈操作
      - 栈不满时
      - 栈顶指针先加1
      - 再送值到栈顶
    - 出栈操作
      - 栈非空时
      - 先取栈顶元素
      - 再将栈顶指针减1
    - 栈状态判断
      - 栈空条件：S.top == -1
      - 栈满条件：S.top == MaxSize-1
      - 栈长：S.top+1
  - 另一种初始设置方式
    - S.top = 0
    - 入栈操作
      - 先送值到栈顶
      - 栈顶指针再加1
    - 出栈操作
      - 栈顶指针先减1
      - 再取栈顶元素
    - 栈状态判断
      - 栈空条件：S.top == 0
      - 栈满条件：S.top == MaxSize
  - 栈上溢问题
    - 顺序栈受数组上界约束
    - 需及时处理栈满情况

- ②. 顺序栈的基本操作

  - (1) 初始化
    - void InitStack(SqStack &S){}
    - S.top = -1;
  - (2) 判栈空
    - bool StackEmpty(SqStack S){}
    - if(S.top == -1) return true;  // 如果栈顶指针为-1，则栈空
    - else return false; // 否则，栈不为空
  - (3) 入栈
    - bool Push(SqStack &S, ElemType x){}
    - if(S.top == MaxSize-1) return false; // 栈顶指针已经到最大，不能加入
    - S.data[++S.top] = x; // 
    - return true;
  - (4) 出栈
    - bool Pop(SqStack &S, ElemType &x){}
    - if(S.top == -1) return false; // 判断栈是否为空，若为空则无法弹出元素
    - x = S.data[S.top--]; // 取出栈顶元素，并将栈顶指针下移一位
    - return true; // 弹出操作成功
  - (5) 读栈顶元素
    - bool GetTop(SqStack S, ElemType &x){}
    - if(S.top == -1) return false; // 判断栈是否为空，若为空则无法获取栈顶元素
    - x = S.data[S.top]; // 获取栈顶元素，但不改变栈顶指针位置
    - return true; // 获取操作成功

- ③. 共享栈

  - 定义
    - 两个顺序栈共享一个一维数组空间
    - 栈底分别设置在共享空间两端
    - 栈顶向中间延伸
  - 栈顶指针设置
    - 0号栈：top0 = -1 时为空
    - 1号栈：top1 = MaxSize 时为空
    - 栈满条件：top1 - top0 == 1
  - 操作特点
    - 0号栈入栈：top0先加1再赋值
    - 1号栈入栈：top1先减1再赋值
    - 出栈操作相反
  - 优点
    - 更有效利用存储空间
    - 空间相互调节
    - 存取时间复杂度仍为O(1)


### 3.1.3    栈的链式存储结构
- 定义
  - 采用链式存储的栈称为链栈
- 优点
  - 便于多个栈共享存储空间
  - 提高效率
  - 不存在栈满上溢的情况
- 实现方式
  - 通常采用单链表实现
  - 所有操作在单链表的表头进行
  - 规定：链栈没有头结点，Lhead指向栈顶元素
- 存储类型描述
  - typedef struct Linknode
    - 数据域
      - ElemType data
    - 指针域
      - struct Linknode *next
  - 栈类型定义
    - LiStack
- 特点
  - 便于结点的插入与删除
  - 操作与链表类似
  - 入栈和出栈操作都在链表表头进行
## 3.2    队 列
### 3.2.1    队列的基本概念
- 队列的定义
  - 队列 (Queue) 简称队，是一种操作受限的线性表
  - 只允许在表的一端进行插入（队尾），另一端进行删除（队头）
  - 插入元素称为入队或进队
  - 删除元素称为出队或离队
  - 操作特性：先进先出 (First In First Out, FIFO)
  - 队列示意图
    - 出队列 ← a₁,a₂,a₃,a₄,a₅ ← 入队列
    - 队头（Front）：允许删除的一端，也称队首
    - 队尾（Rear）：允许插入的一端
  - 空队列：不含任何元素的空表
- 队列常见的基本操作
  - InitQueue(&Q): 初始化队列，构造一个空队列Q
  - QueueEmpty(Q): 判队列空，若队列Q为空返回true，否则返回false
  - EnQueue(&Q,x): 入队，若队列Q未满，将x加入，使之成为新的队尾
  - DeQueue(&Q,&x): 出队，若队列Q非空，删除队首元素，并用x返回
  - GetHead(Q,&x): 读队首元素，若队列Q非空，则将队首元素赋值给x
- 注意事项
  - 栈和队列是操作受限的线性表
  - 不是任何对线性表的操作都可以作为栈和队列的操作
  - 例如：不可以随便读取栈或队列中间的某个数据
### 3.2.2   队列的顺序存储结构
- 队列的顺序存储
  - 定义：分配连续存储单元存放队列元素，设两个指针
    - front指针：指向队首元素
    - rear指针：指向队尾元素的下一个位置
    - 注意：不同教材对front和rear的定义可能不同
    
  - 存储类型描述
    
    - #define MaxSize 50 // 定义队列最大容量为50
    - typedef struct { } SqQueue; // 结构体类型名为 SqQueue
    -     ElemType data[MaxSize]; // 用于存储队列元素的数组
    -     int front, rear; // 队头指针和队尾指针
    
  - 初始状态
    - Q.front = Q.rear = 0
  
  - 基本操作
    - 入队操作
      - 条件：队不满
      - 步骤：
        - 送值到队尾元素
        - 队尾指针加1
    - 出队操作
      - 条件：队不空
      - 步骤：
        - 取队首元素值
        - 队首指针加1
  
  - 队列判空条件
    - Q.front == Q.rear == 0
  - 假溢出问题
    - 现象：队列未满但无法继续入队
    - 原因：数组前端有空位但rear指针已到数组末尾

  - 循环队列
    - 概念：将顺序队列逻辑上视为环状空间
    - 指针运算
      - 初始值：Q.front = Q.rear = 0
      - 指针前进：
        - Q.front = (Q.front + 1) % MaxSize
        - Q.rear = (Q.rear + 1) % MaxSize
      - 队列长度计算：
        - (Q.rear + MaxSize - Q.front) % MaxSize
    - 队空/队满判断
      - 问题：Q.front == Q.rear 可能表示队空或队满
      - 解决方案：
        - 牺牲一个存储单元
          - 队满条件：(Q.rear + 1) % MaxSize == Q.front
          - 队空条件：Q.front == Q.rear
        - 增设size成员
          - 记录元素个数
          - 队空：Q.size == 0
          - 队满：Q.size == MaxSize
        - 增设tag成员
          - 删除成功时tag=0
          - 插入成功时tag=1
          - 根据tag值判断队空/队满
  - 循环队列操作实现
    - 初始化
      - void InitQueue(SqQueue &Q) {}
      - Q.rear = Q.front = 0; // 初始化队头指针和队尾指针为0，表示队列为空
    - 判队空
      - bool isEmpty(SqQueue Q) {}  
      - if (Q.rear == Q.front) // 判断队尾指针是否等于队头指针  
      -     return true; // 相等则队列为空，返回真  
      - else  
      -     return false; // 不相等则队列不为空，返回假
    - 入队操作
      - bool EnQueue(SqQueue &Q, ElemType x) {}  
      - if ((Q.rear + 1) % MaxSize == Q.front) return false; // 判断队列是否已满（预留一个空间作为判断条件）  
      - Q.data[Q.rear] = x; // 将新元素 x 放入队尾指针当前位置  
      - Q.rear = (Q.rear + 1) % MaxSize; // 队尾指针后移一位，取模实现循环效果  
      - return true; // 入队成功，返回真
    - 出队操作
      - bool DeQueue(SqQueue &Q, ElemType &x) {}  
      - if (Q.rear == Q.front) return false; // 判断队列是否为空，若空则无法出队  
      - x = Q.data[Q.front]; // 取出队头元素的值  
      - Q.front = (Q.front + 1) % MaxSize; // 队头指针后移一位，取模实现循环效果  
      - return true; // 出队成功，返回真
### 3.2.3   队列的链式存储结构
- ①. 队列的链式存储

  - 队列的链式表示称为链式队列
    - 是一个同时有队首指针和队尾指针的单链表
    - 队首指针指向队头结点
    - 队尾指针指向队尾结点（单链表的最后一个结点）
  - 不带头结点的链式队列
    - 定义
      - typedef struct{
        - LinkNode *front,*rear;
        - }LinkQueue;
    - 队空条件
      - Q.front==NULL且Q.rear==NULL
    - 操作特点
      - 入队
        - 建立新结点并插入链表尾部
        - Q.rear指向新结点
        - 原队列为空时Q.front也指向该结点
      - 出队
        - 判断队是否为空
        - 取出队首元素并删除
        - Q.front指向下一个结点
        - 若为最后一个结点则置Q.front和Q.rear都为NULL
  - 带头结点的链式队列
    - 优点
      - 插入和删除操作统一
    - 适用场景
      - 数据元素变动较大的情形
      - 不存在队列满溢出的问题
      - 适合使用多个队列的情况

- ②. 链式队列的基本操作

  - (1)初始化
    - void InitQueue(LinkQueue &Q)
      - Q.front=Q.rear=(LinkNode*)malloc(sizeof(LinkNode))
      - Q.front->next=NULL
  - (2)判队空
    - bool ISEmpty(LinkQueue Q)
      - if(Q.front==Q.rear) return true
      - else return false
  - (3)入队
    - void EnQueue(LinkQueue &Q,ElemType x)
      - LinkNode *s=(LinkNode*)malloc(sizeof(LinkNode))
      - s->data=x
      - s->next=NULL
      - Q.rear->next=s
      - Q.rear=s
  - (4)出队
    - bool DeQueue(LinkQueue &Q,ElemType &x)
      - if(Q.front==Q.rear) return false
      - LinkNode *p=Q.front->next
      - x=p->data
      - Q.front->next=p->next
      - if(Q.rear==p) Q.rear=Q.front
      - free(p)
      - return true
### 3.2.4  双 端 队 列
- 定义
  - 允许两端都可以进行插入和删除操作的线性表
  - 左端视为前端，右端视为后端
- 操作特点
  - 入队
    - 前端进的元素排列在后端进的元素前面
    - 后端进的元素排列在前端进的元素后面
  - 出队
    - 先出的元素排列在后出的元素前面
- 受限双端队列
  - 输出受限的双端队列
    - 一端可插入和删除
    - 另一端只允许插入
  - 输入受限的双端队列
    - 一端可插入和删除
    - 另一端只允许删除
    - 特殊情况
      - 若限定从某端点插入的元素只能从该端点删除
      - 蜕变为两个栈底相邻接的栈
- 提示
  - 实际考题通常仅判断序列是否满足题设条件

### 3.3.2    栈在表达式求值中的应用
- 栈在表达式求值中的应用
  - 表达式求值是程序设计语言编译中的基本问题
  - 栈应用的典型范例

- 算术表达式
  - 中缀表达式
    - 特点：操作符位于操作数中间（如3+4）
    - 符合人类思维习惯
    - 需要括号指示运算顺序
  - 前缀表达式
    - 特点：操作符在前（如+34）
  - 后缀表达式
    - 特点：操作符在后（如34+）
    - 不需要括号
    - 运算符优先级已考虑

- 中缀表达式转后缀表达式
  - 计算机实现方法（使用栈）
    - 处理规则：
      - 操作数：直接加入后缀表达式
      - 界限符：
        - "("：直接入栈
        - ")"：弹出栈中运算符直到"("，并删除"("
      - 运算符：
        - 优先级高于栈顶或遇到"("：直接入栈
        - 优先级低于等于栈顶：弹出栈中运算符直到满足条件，再入栈
    - 最终处理：扫描完成后弹出栈中剩余运算符
### 3.3.3   栈在递归中的应用
- 递归定义
  - 函数、过程或数据结构在定义中调用自身
  - 简称递归
- 递归的特点
  - 将复杂问题转化为相似的小规模问题
  - 优点
    - 代码量少
    - 描述多次重复计算
  - 缺点
    - 效率不高
- 斐波那契数列示例
  - 递归实现代码
    - int F(int n){}  
    - if(n == 0) return 0; // 边界条件：当 n 为 0 时，返回 0  
    - else if(n == 1) return 1; // 边界条件：当 n 为 1 时，返回 1  
    - else return F(n-1) + F(n-2); // 递归表达式：斐波那契数列的递归计算  
- 递归模型必要条件
  - 递归表达式（递归体）
  - 边界条件（递归出口）
- 递归本质
  - 将原始问题转换为属性相同但规模较小的问题
- 栈在递归中的作用
  - 函数调用时系统使用递归工作栈
    - 存储返回点
    - 存储局部变量
    - 存储传入实参
  - 问题
    - 递归次数过多会导致栈溢出
- 递归效率问题
  - 原因：包含大量重复计算
  - 优点：代码简单易理解
- 递归转换
  - 可转换为非递归算法
  - 通常需要借助栈实现转换
### 3.3.4    队列在层次遍历中的应用
- 3.3.4 队列在层次遍历中的应用
  - 应用场景
    - 逐层或逐行处理的问题
    - 需要在处理当前层时预处理下一层
    - 使用队列保存下一步处理顺序
### 3.3.5    队列在计算机系统中的应用
- 应用方面一：解决主机与外部设备之间速度不匹配的问题
  - 示例：主机和打印机之间速度不匹配
    - 主机输出数据速度 > 打印机打印速度
    - 解决方法：设置打印数据缓冲区
      - 主机将数据依次写入缓冲区
      - 写满后暂停输出
      - 打印机按先进先出原则取出数据打印
      - 打印完后向主机发出请求
      - 主机接到请求后继续写入数据
    - 缓冲区存储的数据结构：队列
- 应用方面二：解决由多用户引起的资源竞争问题
  - 示例：CPU资源的竞争
    - 多终端计算机系统
    - 多个用户请求占用CPU
    - 操作系统处理方式：
      - 按请求时间先后顺序排成队列
      - 每次分配CPU给队首用户
      - 程序运行结束或时间用完时出队
      - 再分配CPU给新的队首用户
## 3.4   数组和特殊矩阵
### 3.4.1   数组的定义
- 基本概念
  - 由n(n≥1)个相同类型的数据元素构成的有限序列
  - 每个数据元素称为一个数组元素
  - 每个元素在n个线性关系中的序号称为该元素的下标
  - 下标的取值范围称为数组的维界
- 数组与线性表的关系
  - 数组是线性表的推广
  - 一维数组可视为一个线性表
  - 二维数组可视为其元素是定长数组的线性表
  - 以此类推
- 数组的特性
  - 一旦被定义，其维数和维界就不再改变
- 数组的操作
  - 结构的初始化和销毁
  - 存取元素
  - 修改元素
### 3.4.2    数组的存储结构
- 数组的存储特点
  - 大多数计算机语言提供数组数据类型
  - 逻辑意义上的数组可采用计算机语言中的数组数据类型进行存储
  - 所有元素在内存中占用一段连续的存储空间
- 一维数组存储结构
  - 关系式：LOC(aᵢ) = LOC(a₀) + i×L (0≤i<n)
    - L：每个数组元素所占的存储单元
- 二维数组存储方式
  - 按行优先存储
    - 基本思想：先行后列
      - 先存储行号较小的元素
      - 行号相等先存储列号较小的元素
    - 关系式：LOC(aᵢⱼ) = LOC(a₀₀) + [i×(h₂+1)+j]×L
      - 行下标范围：[0,h₁]
      - 列下标范围：[0,h₂]
  - 按列优先存储
    - 关系式：LOC(aᵢⱼ) = LOC(a₀₀) + [j×(h₁+1)+i]×L
### 3.4.3   特殊矩阵的压缩存储
- 压缩存储
  - 指为多个值相同的元素只分配一个存储空间
  - 对零元素不分配空间
- 特殊矩阵
  - 定义：具有许多相同矩阵元素或零元素，且分布有一定规律性的矩阵
  - 常见类型
    - 对称矩阵
    - 上(下)三角矩阵
    - 对角矩阵
  - 压缩存储方法
    - 找出值相同元素的分布规律
    - 将规律性分布的元素压缩存储到一个存储空间
- ①. 对称矩阵
  - 定义：n阶矩阵A中任意元素a_ij = a_ji (1≤i,j≤n)
  - 元素划分
    - 上三角区 (i<j)
    - 下三角区 (i>j)
    - 主对角线 (i=j)
  - 压缩存储方式
    - 存放一维数组B[n(n+1)/2]中
    - 只存放下三角部分(含主对角线)的元素
  - 元素a_ij在数组B中的下标k
    - k = i(i-1)/2 + j-1 (数组下标从0开始)
- ②. 三角矩阵
  - 下三角矩阵
    - 上三角区所有元素为同一常量
    - 压缩存储在B[n(n+1)/2+1]中
    - 存储顺序
      - 下三角区和主对角线元素
      - 对角线上方的常量
    - 元素a_ij在数组B中的下标k
      - k = (i-1)(2n-i+2)/2 + (j-i)
  - 上三角矩阵
    - 压缩存储形式
      - 存储上三角区和主对角线元素
      - 存储下三角区常量
- ③. 三对角矩阵
  - 定义：n阶矩阵A中，当|i-j|>1时，a_ij=0 (1≤i,j≤n)
  - 特点
    - 非零元素集中在以主对角线为中心的3条对角线上
  - 压缩存储方式
    - 按行优先方式存放在一维数组B中
    - a_11存放于B[0]
  - 元素a_ij在数组B中的下标k
    - k = 2i + j - 3
  - 已知k求i,j
    - i = ⌊(k+1)/3⌋ + 1
    - j = k - 2i + 3
### 3.4.4   稀疏矩阵
- 定义
  - 矩阵中非零元素的个数t相对矩阵元素的个数s非常少（s>t）的矩阵
- 存储方法
  - 常规存储方法浪费空间
  - 仅存储非零元素
    - 需要保存的信息
      - 非零元素的值
      - 所在的行和列
  - 三元组表示法
    - 结构：（行标i，列标j，值a）
    - 存储方式
      - 按照某种规律存储三元组线性表
    - 特性
      - 压缩存储后失去随机存取特性
- 存储结构
  - 三元组表存储方式
    - 数组存储
    - 十字链表存储
  - 必须保存的附加信息
    - 稀疏矩阵的行数
    - 稀疏矩阵的列数
    - 非零元素的个数
