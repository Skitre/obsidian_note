# 第二章 线性表
## 2.1 线性表的定义和基本操作
### 线性表的定义
- 线性表的定义
  - 基本概念
    - 具有相同数据类型的n(n≥0)个数据元素的有限序列
    - n为表长
    - n=0时为空表
  - 表示方法
    - 一般表示为L=(a₁,a₂,...,aᵢ,aᵢ₊₁,...,aₙ)
  - 元素特性
    - a₁
      - 第一个数据元素
      - 表头元素
      - 唯一
    - aₙ
      - 最后一个数据元素
      - 表尾元素
      - 唯一
  - 逻辑关系
    - 除第一个元素外
      - 每个元素有且仅有一个直接前驱
    - 除最后一个元素外
      - 每个元素有且仅有一个直接后继
    - 注：直接前驱和前驱、直接后继和后继通常被视为同义词

- 线性表的特点
  - 元素个数有限
  - 元素具有逻辑顺序性
    - 有明确的先后次序
  - 元素性质
    - 都是单个数据元素
  - 数据类型
    - 所有元素数据类型相同
    - 每个元素占相同大小存储空间
  - 抽象性
    - 仅讨论元素间逻辑关系
    - 不考虑元素具体内容
### 线性表的基本操作
- 定义
  - 数据结构最核心、最基本的操作
  - 复杂操作可通过基本操作组合实现
- 主要操作列表
  - InitList(&L)
    - 功能：初始化表
    - 描述：构造一个空的线性表
  - Length(L)
    - 功能：求表长
    - 描述：返回线性表L中数据元素的个数
  - LocateElem(L,e)
    - 功能：按值查找
    - 描述：在表L中查找具有给定关键字值的元素
  - GetElem(L,i)
    - 功能：按位查找
    - 描述：获取表L中第i个位置的元素的值
  - ListInsert(&L,i,e)
    - 功能：插入操作
    - 描述：在表L的第i个位置插入指定元素e
  - ListDelete(&L,i,&e)
    - 功能：删除操作
    - 描述：删除表L中第i个位置的元素，并用e返回删除的值
  - PrintList(L)
    - 功能：输出操作
    - 描述：按顺序输出线性表L的所有元素值
  - Empty(L)
    - 功能：判空操作
    - 描述：若L为空表则返回true，否则返回false
  - DestroyList(&L)
    - 功能：销毁操作
    - 描述：销毁线性表并释放其内存空间

## 2.2 线性表的顺序表示
### 顺序表的定义
- 线性表的顺序存储称为顺序表

- 特点

  - 使用连续地址的存储单元
  - 逻辑相邻的元素物理位置也相邻
  - 第一个元素存储在起始位置
  - 第i个元素后面紧接着第i+1个元素
  - 逻辑顺序与物理顺序相同

- 存储结构图示

  - 数组下标
    - 从0开始
    - 到长度-1结束
  - 顺序表内存地址
    - LOC(A)（起始位置）
    - LOC(A)+(i-1)×sizeof(ElemType)

- 随机存取特性

  - 存储位置与起始位置差和位序成正比
  - 可通过数组实现

- 顺序表实现方式

  - 静态分配

    - 代码实现

      ```c
      #define MaxSize 50
      typedef struct {
        ElemType data[MaxSize];
        int length;
      } SqList;
      ```

    - 缺点

      - 固定大小
      - 空间占满会导致溢出

  - 动态分配

    - 代码实现

      ```c
      #define InitSize 100
      typedef struct {
        ElemType *data;
        int MaxSize, length;
      } SeqList;
      ```

    - 分配语句

      - C语言: `L.data=(ElemType*)malloc(sizeof(ElemType)*InitSize)`
      - C++: `L.data=new ElemType[InitSize]`

    - 特点

      - 仍属于顺序存储
      - 物理结构不变
      - 空间大小可动态决定

- 顺序表特点

  - 优点
    - 随机访问（O(1)时间访问）
    - 存储密度高（只存数据元素）
  - 缺点
    - 插入/删除需要移动大量元素
      - 插入平均移动n/2个
      - 删除平均移动(n-1)/2个
    - 需要连续存储空间
    - 不够灵活
### 顺序表上基本操作的实现
- ①. 顺序表的初始化

  - 静态分配
    - 特点：
      - 声明时已分配数组空间
    - 初始化操作：
      - 将length设为0
  - 动态分配
    - 特点：
      - 需要分配数组空间
      - 维护MaxSize
    - 初始化操作：
      - 分配存储空间
      - length=0
      - 设置MaxSize

- ②. 插入操作

  - 功能：
    - 在第i(1≤i≤L.length+1)个位置插入e
  - 流程：
    - 检查i合法性
    - 检查空间是否已满
    - 元素后移
    - 插入e
    - length++
  - 时间复杂度分析：
    - 最好情况：O(1)（表尾插入）
    - 最坏情况：O(n)（表头插入）
    - 平均情况：O(n)

- ③. 删除操作

  - 功能：
    - 删除第i(1≤i≤L.length)个元素
    - 用e返回被删元素
  - 流程：
    - 检查i合法性
    - 保存被删元素
    - 元素前移
    - length--
  - 时间复杂度分析：
    - 最好情况：O(1)（删除表尾）
    - 最坏情况：O(n)（删除表头）
    - 平均情况：O(n)

- ④. 按值查找（顺序查找）

  - 功能：
    - 查找第一个值等于e的元素
    - 返回其位序
  - 时间复杂度分析：
    - 最好情况：O(1)（表头命中）
    - 最坏情况：O(n)（表尾或不存在）
    - 平均情况：O(n)
  - 按序号查找：
    - 时间复杂度：O(1)


## 2.3 线性表的链式表示
### 单链表的定义
- 定义
  - 线性表的链式存储
  - 通过一组任意的存储单元存储数据元素
  - 每个结点包含：
    - data域：存放数据元素
    - next域：存放后继结点地址
- 结点结构
  - data：当前节点数据
  - next：下一个节点的指针
- 特点
  - 优点
    - 解决顺序表需要连续存储的问题
  - 缺点
    - 指针域浪费存储空间
    - 非随机存取结构
- 头指针
  - 标识单链表的起始地址
  - NULL表示空表
- 头结点
  - 附加在第一个数据结点之前
  - 数据域可选
    - 可存储表长等信息
  - 两种形式
    - 带头结点的单链表：头指针指向头结点
    - 不带头结点的单链表：头指针指向第一个数据结点
  - 表尾结点指针域为NULL
- 头结点与头指针关系
  - 头指针始终指向链表第一个结点
  - 头结点是带头结点链表中的第一个结点
- 头结点的优点
  - 统一第一个位置和其他位置的操作
  - 统一空表和非空表的处理


### 单链表上基本操作的实现
- ①. 单链表的初始化
  - 带头结点和不带头结点的初始化不同
    - 带头结点初始化：
      - 创建头结点
      - 头指针指向头结点
      - 头结点的next域初始化为NULL
    - 不带头结点初始化：
      - 头指针L初始化为NULL
  - 结点访问说明：
    - p->data 等价于 (*p).data
    - p->next->data 表示下一个结点的数据
- ②. 求表长操作
  - 计算数据结点个数（不包括头结点）
  - 从第一个结点开始遍历计数
  - 时间复杂度：O(n)
  - 注意：带头结点与不带头结点的实现有差异
  
- ③. 按序号查找结点
  - 从第一个结点开始顺序查找第i个结点
  - 时间复杂度：O(n)
  
- ④. 按值查找表结点
  - 从第一个结点开始比较数据域
  - 时间复杂度：O(n)
  
- ⑤. 插入结点操作
  - 将新结点插入到第i个位置
  - 操作步骤：
    - 找到第i-1个结点（前驱）
    - 新结点指向后继
    - 前驱指向新结点
  - 时间复杂度：O(n)
  - 注意：操作顺序不可颠倒
  - 前插操作扩展：
    - 可转化为后插+数据交换
    - 时间复杂度降为O(1)
  
- ⑥. 删除结点操作
  - 删除第i个结点
  - 操作步骤：
    - 找到第i-1个结点（前驱）
    - 修改前驱的指针域
    - 释放被删结点
  - 时间复杂度：O(n)
  - 扩展：删除指定结点*p
    - 可通过后继结点操作实现
    - 时间复杂度降为O(1)
  
- ⑦. 头插法建立单链表
  - 新结点始终插入在头结点之后
  - 生成的链表是逆序的
  - 时间复杂度：O(n)
  - 注意：不带头结点时需要特殊处理首结点
  
- ⑧. 尾插法建立单链表
  - 新结点始终插入在链表尾部
  - 生成的链表是正序的
  - 需要维护尾指针
  - 时间复杂度：O(n)
### 双链表
- 单链表的局限性
  - 单链表结点只有一个指向后继的指针
  - 只能从前往后遍历
  - 访问前驱需要O(n)时间复杂度
- 双链表改进
  - 增加prior指针指向直接前驱
  - 结点结构
    - prior: 指向前驱
    - data: 数据域
    - next: 指向后继
  - 表头结点prior为NULL
  - 尾结点next为NULL
- 双链表结点类型定义
  - ElemType data;   // 数据域
  - struct DNode *prior; // 前驱指针
  - struct DNode *next;  // 后继指针
- 操作特点
  - 查找操作与单链表相同
  - 插入/删除操作不同
    - 需要维护prior指针
    - 时间复杂度O(1)
- 插入操作
  - 在p结点后插入s结点
    - 步骤
      - s->next = p->next
      - p->next->prior = s
      - s->prior = p
      - p->next = s
    - 注意事项
      - 步骤1必须在步骤4之前
      - 防止断链
- 删除操作
  - 删除p的后继结点q
    - 步骤
      - p->next = q->next
      - q->next->prior = p
      - free(q)
- 建立双链表
  - 可采用头插法和尾插法
  - 需要注意指针变化与单链表不同
### 循环链表
- 2.3.4 循环链表
  - ①. 循环单链表
    - 定义
      - 与单链表的区别
        - 最后一个结点的指针指向头结点
        - 整个链表形成环状结构
    - 特点
      - 表尾结点*r的next域指向头结点
      - 没有NULL指针的结点
      - 判空条件
        - 头结点指针是否等于头指针
    - 操作特性
      - 插入/删除算法与单链表基本相同
        - 表尾操作需要特殊处理以保持循环性质
      - 优势
        - 任意位置操作等价
        - 可从任意结点开始遍历
    - 实现优化
      - 尾指针设置
        - 优点
          - 表头/表尾插入时间复杂度O(1)
          - 相比头指针实现效率更高
  - ②. 循环双链表
    - 结构特点
      - 头结点的prior指针指向表尾结点
      - 尾结点的next指针指向头结点
    - 特殊情况
      - 尾结点判断
        - p->next == L
      - 空表状态
        - 头结点的prior和next域都等于L

### 静态链表
- 静态链表概念
  - 用数组描述线性表的链式存储结构
  - 结点组成
    - 数据域 data
    - 指针域 next
  - 指针特点
    - 表示结点在数组中的相对地址（数组下标/游标）
  - 存储要求
    - 需要预先分配连续内存空间

- 结构定义
  - #define MaxSize 50 //静态链表的最大长度
  - typedef struct {}SLinkList[MaxSize];
  - ElemType data; //存储数据元素
  - int next; // 下一个元素的数组下标

- 结束标志
  - next == -1 表示链表结束

- 操作特点
  - 插入/删除操作
    - 与动态链表操作相同
    - 只需修改指针
    - 不需要移动元素

- 优缺点
  - 优点: 在不支持指针的语言中（如Basic）可实现链式结构
  - 缺点: 使用便利性不如单链表
### 顺序表和链表的比较
- 存取(读/写)方式
  - 顺序表
    - 可以顺序存取
    - 可以随机存取
    - 第i个位置存取只需一次访问
  - 链表
    - 只能顺序存取
    - 第i个位置存取需要访问i次
- 逻辑结构与物理结构
  - 顺序存储
    - 逻辑相邻则物理相邻
  - 链式存储
    - 逻辑相邻不一定物理相邻
    - 通过指针表示逻辑关系
- 查找、插入和删除操作
  - 按值查找
    - 无序时
      - 顺序表: O(n)
      - 链表: O(n)
    - 有序时
      - 顺序表: O(log₂n) (折半查找)
  - 按序号查找
    - 顺序表: O(1)
    - 链表: O(n)
  - 插入/删除
    - 顺序表
      - 平均移动半个表长元素
    - 链表
      - 只需修改指针
- 空间分配
  - 顺序存储
    - 静态分配
      - 空间固定不能扩充
      - 需要预先分配
        - 过大导致闲置
        - 过小导致溢出
    - 动态分配
      - 可以扩充但效率低
      - 需要连续存储空间
  - 链式存储
    - 按需申请空间
    - 存储密度较低(含指针域)
- 存储结构选择标准
  - 基于存储的考虑
    - 顺序表
      - 需要预估长度
    - 链表
      - 无需预估
      - 存储密度低
  - 基于运算的考虑
    - 按序号访问
      - 顺序表: O(1) (优)
      - 链表: O(n)
    - 插入/删除
      - 顺序表: 移动元素多
      - 链表: 主要比较操作(优)
  - 基于环境的考虑
    - 顺序表
      - 实现简单(有数组支持)
    - 链表
      - 基于指针实现较复杂
  - 总结选择原则
    - 稳定线性表: 顺序存储
    - 频繁插入删除: 链式存储
