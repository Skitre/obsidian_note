# 第四章 串
## 4.2    串的模式匹配
### 4.2.2    串的模式匹配算法——KMP算法
- KMP算法原理
  - 传统匹配算法问题
    - 每趟匹配失败后模式串仅右移一位
    - 主串指针需要回溯
  - 改进思路
    - 利用已匹配前缀信息减少比较次数
    - 主串指针不回溯
  - 核心概念
    - 前缀：除最后一个字符外的所有头部子串
    - 后缀：除第一个字符外的所有尾部子串
    - 部分匹配值(PM)：最长相等前后缀长度
- next数组手算方法
  - 定义
    - next[j]：第j个字符失配时跳转的位置
  - 计算方法
    - next[1]=0（特例处理）
    - 通过PM表转换
      - next[j]=PM[j-1]+1
- next数组推理公式
  - 基本公式
    - next[1]=0
    - 当Pk=Pj时：next[j+1]=k+1
    - 当Pk≠Pj时：递归寻找更小的k'
  - 递推求解步骤
    - 初始化next[1]=0
    - 根据当前匹配情况递推后续值
- KMP算法实现
  - get_next函数
    - 计算next数组
    - 时间复杂度O(m)
  - Index_KMP函数
    - 主匹配过程
    - 时间复杂度O(n)
  - 算法特点
    - 主串指针不回溯
    - 时间复杂度O(m+n)
    - 适合部分匹配较多的情况
- 算法比较
  - 与朴素匹配算法对比
    - 普通匹配：最坏O(mn)，平均O(m+n)
    - KMP匹配：稳定O(m+n)
    - KMP优势：主串不回溯
### 4.2.3  KMP 算法的进一步优化
- 优化原因
  - 原next数组在某些情况下有缺陷
- 问题分析
  - 问题在于pj=Pnext[j]
  - 会导致继续用相同字符比较
  - 必然继续失配
- 解决方案
  - 出现pj=Pnext[j]时需要递归修正
  - 将next[j]修正为next[next[j]]
  - 直到两者不相等
  - 更新后的数组命名为nextval
- 算法实现
  - get_nextval函数
    - 参数：SString T, int nextval[]
    - 初始化：i=1,j=0,nextval[1]=0
    - 循环条件：i<T.length
    - 分支处理：
      - if(j==0||T.ch[i]==T.ch[j])
        - i++,j++
        - 判断T.ch[i]!=T.ch[j]
          - 是：nextval[i]=j
          - 否：nextval[i]=nextval[j]
      - else
        - j=nextval[j]
