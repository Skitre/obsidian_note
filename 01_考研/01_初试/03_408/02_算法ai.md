## 顺序表
### 一、顺序表特性
支持随机访问-----可用下标、二分查找、快排
内存连续-----缓存友好，适合批量处理
插入/删除需移动元素-----不适合频繁删减
### 二、核心技巧
#### 技巧 1、有序 → 折半查找（二分法）

**适合场景**
- 数组**整体有序** 或 **局部有序**（如旋转数组）
- 要求时间复杂度 **优于 O(n)**
**真题**
- 2011年真题：在两个有序数组中找第k小元素（可用二分优化归并）
- 变种题：旋转排序数组找最小值、搜索目标值
**代码模板**
```
// 模板一：找第一个 >= target 的位置（左边界）
int binarySearchLeft(int A[], int n, int target) {
    int left = 0, right = n; // 注意 right = n
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (A[mid] < target)
            left = mid + 1;
        else
            right = mid;
    }
    return left; // 若返回值 < n 且 A[left]==target，则找到
}

// 模板二：找最后一个 <= target 的位置（右边界）
int binarySearchRight(int A[], int n, int target) {
    int left = -1, right = n - 1;
    while (left < right) {
        int mid = left + (right - left + 1) / 2;
        if (A[mid] > target)
            right = mid - 1;
        else
            left = mid;
    }
    return left;
}
```
#### 技巧 2：数据范围有限 → 散列表（计数数组）
**适用场景**
- 元素是整数，且范围明确
- 需要快速判重、统计频次
**需要注意**
- 确认数据合法性
- 空间复杂度 O（M），M 为值域大小
**代码模版**

```
void findDuplicates(int A[], int n) {

        if (count[A[i]] > 0) {
            cout << A[i] << " "; // 已出现过，是重复元素
        }
        count[A[i]]++;
    }
}
```

##### 预处理 2、动态维护最值（滑动窗口）
**适用场景**
- 长度为 k 的子数组最大值（18 年真题）
**代码模板**
简化版（非单调队列）
```
int maxInWindow(int A[], int n, int k) {
    int res = INT_MIN;
    for (int i = 0; i <= n - k; i++) {
        int curMax = *max_element(A + i, A + i + k); // 实际应优化
        res = max(res, curMax);
    }
    return res;
}
```
单调队列
```
#include <deque>
using namespace std;

void slidingWindowMax(int A[], int n, int k, int M[]) {
    deque<int> dq; // 存储下标
    int idx = 0;

    for (int i = 0; i < n; i++) {
        // 1. 移除队首过期元素（不在窗口内）
        if (!dq.empty() && dq.front() <= i - k)
            dq.pop_front();

        // 2. 从队尾移除所有 <= A[i] 的元素（维护单调递减）
        while (!dq.empty() && A[dq.back()] <= A[i])
            dq.pop_back();

        // 3. 当前下标入队
        dq.push_back(i);

        // 4. 窗口形成后记录最大值
        if (i >= k - 1)
            M[idx++] = A[dq.front()];
    }
}
```

```
void merge(int A[], int m, int B[], int n) {
    int i = m - 1, j = n - 1, k = m + n - 1;
    while (i >= 0 && j >= 0) {
        if (A[i] > B[j])
            A[k--] = A[i--];
        else
            A[k--] = B[j--];
    }
    while (j >= 0) A[k--] = B[j--]; // B剩余
```

```
    if (n == 0) return 0;
    int slow = 1;
    for (int fast = 1; fast < n; fast++) {
        if (A[fast] != A[fast - 1])
            A[slow++] = A[fast];
    }
    return slow; // 新长度
}
```


## 链表

> 目标：掌握考研中链表相关大题的**核心解法、代码模板与真题应用**  
> 学习原则：**指针驱动，画图辅助；先保正确，再求优化**

---

### 一、链表核心特性回顾

| 特性 | 对算法的影响 |
|------|-------------|
| **不支持随机访问** | ❌ 不能用下标、不能折半查找、不能快排 |
| **只能顺序遍历** | ✅ 所有操作必须从头开始 |
| **插入/删除 O (1)**（已知前驱） | ✅ 适合频繁结构调整 |
| **内存不连续** | ⚠️ 缓存不友好，但灵活 |

> ⚠️ **关键限制（考试必看）**：  
> - 若题目说“**不可修改链表结构**”，则不能反转、不能重排  
> - 若要求“**空间复杂度 O (1)**”，则不能转数组、不能用哈希表

---

### 二、四大核心优化技巧（必须掌握）

#### 技巧 1：多指针法（绝对核心！）

##### （1）快慢指针（Fast-Slow Pointers）

###### ✅ 应用场景
- 找链表中点（用于回文判断、分治）
- 判断链表是否有环（Floyd 判圈算法）
- 找环的入口节点

###### 🔧 模板代码

```cpp
// 找中点（偶数时返回中间靠左的节点）
LNode* findMiddle(LNode* head) {
    if (!head) return nullptr;
    LNode *slow = head, *fast = head;
    while (fast->next && fast->next->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow; // 中点
}

// 判断是否有环
bool hasCycle(LNode* head) {
    if (!head || !head->next) return false;
    LNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true; // 相遇即有环
    }
    return false;
}
```

> 💡 考研重点：**找中点 + 判环** 是组合题基础（如回文链表）

---

##### （2）前后指针（双指针间隔 k）

###### ✅ 应用场景
- 找倒数第 k 个节点（**2009 年真题**）
- 删除倒数第 k 个节点

###### 🔧 模板代码（带边界检查）

```cpp
// 查找倒数第k个节点（k从1开始计数）
LNode* findKthFromEnd(LNode* head, int k) {
    if (!head || k <= 0) return nullptr;
    
    LNode *front = head, *back = head;
    
    // 先让 front 走 k-1 步
    for (int i = 0; i < k - 1; i++) {
        if (!front->next) return nullptr; // k 大于链表长度
        front = front->next;
    }
    
    // 同时移动，直到 front 到尾
    while (front->next) {
        front = front->next;
        back = back->next;
    }
    
    return back; // 即倒数第k个
}
```

> 📌 **2009 年真题要求**：  
> - 不改变链表结构  
> - 输出 data 值并返回 1，否则返回 0  
> - 必须处理 `k > 长度` 的情况！

---

#### 技巧 2：头插法 / 尾插法

##### （1）头插法 → 用于**逆置链表**

###### 🔧 模板代码（迭代版，推荐）

```cpp
LNode* reverseList(LNode* head) {
    LNode *prev = nullptr, *curr = head;
    while (curr) {
        LNode* next = curr->next; // 保存下一个
        curr->next = prev;        // 头插：当前节点指向前一个
        prev = curr;              // 更新 prev
        curr = next;              // 继续下一个
    }
    return prev; // 新头结点
}
```

> ✅ 优点：O (1) 空间，原地反转  
> ❌ 注意：若题目说“不可修改结构”，则不能用！

##### （2）尾插法 → 用于**合并有序链表、构建新链表**

```cpp
LNode* mergeTwoLists(LNode* l1, LNode* l2) {
    LNode dummy(0); // 虚拟头节点
    LNode* tail = &dummy;
    
    while (l1 && l2) {
        if (l1->data <= l2->data) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;
    }
    
    Tail->next = l 1 ? L 1 : l 2; // 接上剩余部分
    Return dummy. Next;
}
```

> 💡 **虚拟头节点（dummy）是链表题高分关键**！避免处理头节点边界。

---

#### 技巧 3：散列表（辅助判重）

###### ✅ 适用场景
- 删除重复节点（保留一个 or 全删）
- 判断两个链表是否相交（通过地址）

###### 🔧 示例：删除重复节点（保留一个）

```cpp
Void removeDuplicates (LNode* head) {
    If (! Head) return;
    unordered_set<int> seen;
    LNode* curr = head;
    Seen.Insert (curr->data);
    
    While (curr->next) {
        If (seen.Count (curr->next->data)) {
            LNode* toDel = curr->next;
            Curr->next = toDel->next;
            Delete toDel; // 若需释放内存
        } else {
            Seen.Insert (curr->next->data);
            Curr = curr->next;
        }
    }
}
```

> ⚠️ **注意**：若题目要求 **O (1) 空间**，则此方法**不可用**！需用双重循环（O (n²)）。

### 三、链表基本操作（必须手写熟练）

| 操作            | 关键点                                         |
| ------------- | ------------------------------------------- |
| **遍历**        | `while (p != nullptr)`                      |

## 树与二叉树

> 目标：掌握考研中树/二叉树大题的**递归解法、遍历选择逻辑与标准答题模板**  
> 学习原则：**优先递归，代码简洁；审题定序，框架先行**

---

## 一、核心方法论：**递归遍历是树算法的唯一主线**

### ✅ 为什么优先用递归？

- 考研不要求“优化”（如非递归、空间压缩）
- 递归代码**短、清晰、易写、不易错**
- 阅卷按“逻辑正确性”给分，**不考性能**

> 📌 讲义强调：**除非题目明确要求“非递归”或“空间复杂度 O(1)”，否则一律用递归！**

---

## 二、如何选择遍历方式？—— 三问定乾坤

面对任何树题，先问自己：

|问题|对应遍历|典型场景|
|---|---|---|
|**处理当前节点是否需要左/右子树的结果？**  <br>（如高度、平衡性）|→ **后序遍历**|求深度、判断AVL、求繁茂度|
|**当前节点的值是否影响子树处理？**  <br>（如路径和、带权深度）|→ **先序遍历**|求节点总数、路径和、复制树|
|**是否涉及“顺序”或BST性质？**  <br>（如输出中缀、验证有序）|→ **中序遍历**|判断BST、输出表达式、找第k小|

> 💡 **口诀速记**：
> 
> - **后序**：子树结果 → 根（“自底向上”）
> - **先序**：根 → 影响子树（“自顶向下”）
> - **中序**：左 → 根 → 右（“顺序相关”）

---

## 三、“审题-写框架-填充-调整”四步法（讲义4.3节精髓）

### 步骤1️⃣：审题 → 明确“visit(p)”要做什么

- 提取关键词：
    - “叶子数” → 判断 `p->lchild == nullptr && p->rchild == nullptr`
    - “高度” → 返回 `max(left_h, right_h) + 1`
    - “是否BST” → 中序遍历是否递增

### 步骤2️⃣：写遍历框架（只写结构，不填逻辑）

```cpp
// 以中序为例（其他只需换顺序）
void traverse(BTNode* p) {
    if (!p) return;
    traverse(p->lchild);   // 左
    visit(p);              // 根 ← 核心操作在此
    traverse(p->rchild);   // 右
}
```

> ✅ 建议：先默写三种遍历框架，再填 `visit(p)`

### 步骤3️⃣：填充 visit(p) 逻辑

- 根据题目要求，在 `visit(p)` 位置写具体操作
- 若需返回值（如高度），改写为带返回值的函数

### 步骤4️⃣：调整边界 & 全局变量（如有）

- 空树处理（`if (!p) return ...`）
- 全局计数器（如 leaf_count）需在主函数初始化

---

## 四、高频题型与标准模板（递归版）

### 题型1：求叶子节点个数（先序/中序/后序均可）

```cpp
int countLeaves(BTNode* root) {
    if (!root) return 0;
    if (!root->lchild && !root->rchild)
        return 1;
    return countLeaves(root->lchild) + countLeaves(root->rchild);
}
```

> 📌 遍历方式任意，因**仅依赖当前节点属性**

---

### 题型2：求二叉树高度（必须后序）

```cpp
int getDepth(BTNode* root) {
    if (!root) return 0;
    int leftH = getDepth(root->lchild);
    int rightH = getDepth(root->rchild);
    return 1 + max(leftH, rightH); // 必须等子树结果
}
```

---

### 题型3：判断是否为平衡二叉树（AVL）（后序）

```cpp
// 返回子树高度；若不平衡，返回 -1
int checkBalance(BTNode* root) {
    if (!root) return 0;
    
    int leftH = checkBalance(root->lchild);
    if (leftH == -1) return -1;
    
    int rightH = checkBalance(root->rchild);
    if (rightH == -1) return -1;
    
    if (abs(leftH - rightH) > 1) return -1;
    return 1 + max(leftH, rightH);
}

bool isAVL(BTNode* root) {
    return checkBalance(root) != -1;
}
```

---

### 题型4：判断是否为二叉搜索树（BST）（中序）

```cpp
// 全局变量记录前一个值
int prev = INT_MIN;
bool isFirst = true;

bool isValidBST(BTNode* root) {
    if (!root) return true;
    
    if (!isValidBST(root->lchild)) return false;
    
    // visit(root)
    if (!isFirst && root->data <= prev) return false;
    prev = root->data;
    isFirst = false;
    
    return isValidBST(root->rchild);
}
```

> ⚠️ 注意：不能只比较 `root->data > root->lchild->data`，需全局有序！
