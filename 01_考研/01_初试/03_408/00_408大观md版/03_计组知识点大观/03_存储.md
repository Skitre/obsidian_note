### 3.1.2 存储器的性能指标

- 存储器有三个主要性能指标

- 存储容量
- 单位成本
- 存储速度

- 设计目标

- 大容量
- 低成本
- 高速度

1. 存储容量

- 计算公式

- 存储容量=存储字数×字长

- 单位换算

- 1B(Byte)=8b(bit)

- 存储字数

- 表示存储器的地址空间大小

- 字长

- 表示一次存取操作的数据量

1. 单位成本

- 计算公式

- 位价=总成本/总容量

1. 存储速度

- 数据传输速率

- 计算公式

- 数据的宽度/存取周期

- ① 存取时间(Ta)

- 定义

- 从启动操作到完成操作的时间

- 分类

- 读出时间
- 写入时间

- ② 存取周期(Tm)

- 定义

- 完整读/写操作所需时间
- 连续两次独立操作的最小间隔

- ③ 主存带宽(Bm)

- 别名

- 数据传输速率

- 定义

- 每秒进出主存的最大信息量

- 单位

- 字/秒
- 字节/秒(B/s)
- 位/秒(b/s)

- 存取时间与周期关系

- 存取周期>存取时间
- 原因

- 需要恢复内部状态的复原时间

- 破坏性读出存储器

- 存取周期可能远大于存取时间
- 原因

- 需要立即进行信息再生

### 3.1.3 多级层次的存储系统

- 解决存储系统三大矛盾

- 大容量
- 高速度
- 低成本

- 多级存储器结构特点

- 由上至下

- 位价越来越低
- 速度越来越慢
- 容量越来越大
- CPU访问频度越来越低

- 主要层次结构

- Cache-主存层

- Cache

- 与CPU直接交换信息
- 作为主存的高速缓存

- Cache-主存层特点

- 速度接近Cache
- 容量和位价接近主存
- 解决CPU和主存速度不匹配问题
- 数据调动由硬件自动完成
- 对程序员透明

- 主存-辅存层

- 主存

- 与CPU、Cache、辅存交换信息

- 辅存

- 通过主存与CPU交换信息

- 主存-辅存层特点

- 速度接近主存
- 容量和位价接近辅存
- 解决存储系统容量问题
- 数据调动由硬件和OS共同完成
- 对应用程序员透明

- 虚拟存储系统

- 程序员地址范围对应虚拟地址空间
- 可用地址空间远大于主存空间

- 三级存储系统层次结构

- CPU访问流程

- 先访问Cache
- 不在Cache则访问主存
- 不在主存则访问磁盘

- 数据流向

- 磁盘→主存→Cache

### 3.2.2 只读存储器

- ①. 只读存储器 (ROM) 的特点

- RAM 和ROM 的区别(2010)

- ROM 和 RAM 都是支持随机访问的存储器
- SRAM 和DRAM 均为易失性半导体存储器
- ROM 特点：

- 信息不能轻易改变
- 掉电不会丢失

- ROM 优点：

- ① 结构简单，位密度比可读/写存储器高
- ② 具有非易失性，可靠性高

- ②. ROM 的类型

- (1) 掩模式只读存储器 (MROM)

- 内容由半导体制造厂商直接写入
- 优点：

- 可靠性高
- 集成度高
- 价格便宜

- 缺点：

- 灵活性差

- (2) 一次可编程只读存储器 (PROM)

- 可实现一次性编程
- 写入后内容无法改变

- (3) 可擦除可编程只读存储器 (EPROM)

- 可多次改写
- 不能取代 RAM 的原因：

- 编程次数有限
- 写入时间过长

- (4) Flash 存储器

- Flash存储器的特点(2012)
- 特点：

- 兼有ROM 和 RAM 的优点
- 长期保存信息
- 在线快速擦除与重写
- 价格便宜、集成度高
- 电可擦除重写
- 擦除重写速度快

- (5) 固态硬盘 (Solid State Drive, SSD)

- 基于闪存的固态硬盘
- 组成：

- 控制单元
- 存储单元 (Flash芯片)

- 特性：

- 保留 Flash 存储器特性
- 读/写速度快
- 低功耗

- 缺点：

- 价格较高

### 3.3.2 主存容量的扩展

- 单个存储芯片的容量是有限的

- 需要在字和位两方面进行扩充

- 位扩展法

- 定义

- 对字长进行扩展(增加存储字长)

- 适用场景

- CPU系统数据线数多于存储芯片的数据位数

- 连接方式

- 各芯片的地址线、片选控制线和读/写控制线与系统总线相应并联
- 各芯片的数据线单独引出，分别连接系统数据线

- 特点

- 各芯片同时工作

- 字扩展法

- 定义

- 对存储字的数量进行扩展

- 适用场景

- 系统数据线位数等于芯片数据线位数
- 系统地址线位数多于芯片地址线位数

- 连接方式

- 各芯片的地址线与系统地址线的低位对应相连
- 芯片的数据线和读/写控制线与系统总线相应并联
- 由系统地址线的高位译码得到各芯片的片选信号

- 特点

- 各芯片分时工作

- 字位同时扩展法

- 定义

- 前两种扩展的组合
- 既增加存储字的数量，又增加存储字长

- 连接方式

- 将进行位扩展的芯片作为一组
- 各组的连接方式与位扩展的相同
- 由系统地址线高位译码产生若干片选信号

### 3.3.3 存储芯片的地址分配和片选

- 适用场景

- 当线选法地址线不足时使用

### 3.4.2 固态硬盘

- 固态硬盘的特性

- 固态硬盘 (SSD) 是一种基于闪存技术的存储器
- 与U盘无本质差别，容量更大，存取性能更好
- 组成

- 闪存芯片
- 闪存翻译层

- 将CPU逻辑块读/写请求翻译为物理设备控制信号
- 相当于磁盘控制器角色

- 结构特点

- 闪存由B个块组成

- 每块由P页组成

- 页大小：512B~4KB
- 每块32~128页
- 块大小：16KB~512KB

- 数据以页为单位读/写
- 以块为单位擦除

- 写入特点

- 随机写慢的原因

- 擦除块较慢
- 修改已有数据页时需要复制整个块

- 优点

- 随机访问时间快
- 无机械噪声和振动
- 能耗低
- 抗震性好
- 安全性高

## 3.5 高速缓冲存储器

### 3.5.1 程序访问的局部性原理

- 时间局部性

- 最近的未来要用到的信息很可能是现在正在使用的信息
- 原因

- 程序中存在循环
- 需要多次重复执行的子程序段
- 对数组的存储和访问操作

- 空间局部性

- 最近的未来要用到的信息很可能与现在正在使用的信息在存储空间上是邻近的
- 原因

- 指令通常是顺序存放、顺序执行的
- 数据一般以向量、数组等形式簇聚地存储

- 高速缓冲技术应用

- 利用局部性原理
- 把正在使用的部分数据存放在高速、容量较小的Cache中
- 使CPU访存操作大多数针对Cache进行
- 提高程序执行速度

- 例题分析

- 程序A和程序B比较

- 数组a访问的空间局部性

- 程序A

- 访问顺序与存放顺序一致
- 空间局部性好

- 程序B

- 访问顺序与存放顺序不一致
- 每次访问跳过2048个数组元素
- 若主存与Cache交换单位小于8KB则没有空间局部性

- 数组a的时间局部性

- 两个程序都差
- 每个数组元素都只被访问一次

- for循环体的访问局部性

- 程序A和程序B相同

- 空间局部性好（指令按序连续存放）
- 时间局部性好（内循环体被连续重复执行2048×2048次）

- 结论

- 程序A和程序B功能相同
- 因循环顺序不同导致对数组a访问的空间局部性差异
- 带来执行时间的巨大差异

### 3.5.3 Cache 和主存的映射方式

- Cache 行数比主存块数少得多

- 需要为每块加标记位
- 标记内容相当于主存中块的编号
- 每个Cache 行需要一个有效位

- 地址映射方法

- 直接映射

- 主存中的每一块只能装入Cache 中的唯一位置
- 特点

- 实现简单
- 不够灵活
- 块冲突概率最高
- 空间利用率最低

- 映射关系

- Cache 行号=主存块号 mod Cache 总行数

- 地址结构

- 主存地址分为三部分

- 高t位：标记
- 中间c位：Cache 行号
- 低位：块内地址

- CPU 访存过程

- 根据访存地址中间的c位找到对应Cache 行
- 比较标记和有效位
- 命中则存取信息
- 不命中则从主存读取

- 全相联映射

- 主存中的每一块可以装入Cache 中的任何位置
- 特点

- 冲突概率低
- 空间利用率高
- 命中率高
- 标记比较速度慢
- 实现成本高

- 地址结构

- 主存地址分为两部分

- 高位：标记
- 低位：块内地址

- CPU 访存过程

- 将主存地址的高位标记与Cache 各行的标记比较
- 命中则取出信息
- 不命中则从主存读取

- 组相联映射

- 将Cache 分成Q个大小相等的组
- 组间采用直接映射，组内采用全相联映射
- 特点

- 成本接近直接映射
- 性能接近全相联映射

- 映射关系

- Cache 组号=主存块号 mod Cache 组数

- 地址结构

- 主存地址分为三部分

- 高位：标记
- 中间：组号
- 低位：块内地址

- CPU 访存过程

- 根据访存地址中间的组号找到对应Cache 组
- 比较标记和有效位
- 命中则存取信息
- 不命中则从主存读取

- 三种映射方式比较

- 命中率

- 直接映射最低
- 全相联映射最高

- 判断开销

- 直接映射最小
- 全相联映射最大

- 额外空间开销

- 直接映射最少
- 全相联映射最多

### 3.5.5 Cache 的一致性问题

![](https://cdn.nlark.com/yuque/0/2025/png/58136020/1758354109361-3d8b242a-2c89-4a9a-9659-eaf1e695622c.png)

![](https://cdn.nlark.com/yuque/0/2025/png/58136020/1758354137314-d2ec5bc9-b64f-4946-8c06-9a294eaa4e03.png)

![](https://cdn.nlark.com/yuque/0/2025/png/58136020/1758354218109-b10078c8-11ed-454d-bd4b-3f065c39ddac.png)

- 原因: Cache 是主存块副本，更新Cache时需保持主存一致
- 写操作策略分两种情况

- Cache写操作命中(Write Hit)

- 全写法(直写法、Write Through)

- 特点: 同时写入Cache和主存
- 优点: 实现简单，保持主存数据正确
- 缺点: 增加访存次数，降低Cache效率
- 写缓冲

- 作用: 减少全写法时间损耗
- 原理: CPU同时写Cache和写缓冲，缓冲再写主存
- 问题: 频繁写时可能使缓冲溢出

- 回写法(Write Back)

- 特点: 只写入Cache，替换时才写回主存
- 优点: 减少访存次数
- 缺点: 存在数据不一致隐患
- 修改位(脏位)

- 作用: 标记Cache行是否被修改
- 1: 需写回主存
- 0: 无需写回主存

- Cache写操作不命中

- 写分配法(Write Allocate)

- 步骤: 更新主存单元后调入Cache
- 优点: 利用空间局部性
- 缺点: 每次不命中都需读主存块

- 非写分配法(Not-Write-Allocate)

- 步骤: 只更新主存单元
- 通常与全写法合用

- 分离的Cache结构

- 原因: 解决指令预取与数据存取冲突
- 优点

- 利用指令和数据的不同局部性
- 优化性能

- 实现: 一般在L1级分离指令Cache和数据Cache

- 多级Cache

- 层级: L1 Cache、L2 Cache等
- 特点

- 离CPU越远，速度越慢，容量越大
- L1对L2通常用全写法
- L2对主存通常用回写法

## 3.6 虚拟存储器

### 3.6.1 虚拟存储器的基本概念

- 地址空间统一编址

- 主存或辅存的地址空间统一编址
- 形成庞大的地址空间
- 用户自由编程，不考虑实际主存容量和程序存放位置

- 地址类型

- 虚地址（逻辑地址）

- 用户编程允许涉及的地址
- 对应虚拟空间或程序空间

- 实地址（物理地址）

- 实际主存单元地址
- 对应主存地址空间（实地址空间）

- 虚地址比实地址大很多

- 地址空间示意图

- 虚拟存储器的三个地址空间

- CPU访问流程

- 判断虚地址内容是否已装入主存

- 已装入：通过地址变换直接访问主存实际单元
- 未装入：

- 调入包含该字的一页或一段到主存
- 若主存已满，采用替换算法置换主存中的交换块（页面）

- 技术特点

- 类似Cache技术

- 将辅存中经常访问的数据副本存放到主存

- 关键点

- 缺页（或段）访问辅存代价大
- 提高命中率是关键

- 映射方式

- 采用全相联映射

- 每个虚页面可存放到主存区域任何空闲页位置

- 写操作处理

- 不能每次写操作都同时写回磁盘
- 采用回写法处理一致性问题

### 3.6.2 页式虚拟存储器

- 基本概念

- 主存空间和虚拟地址空间被划分成相同大小的页
- 主存中的页称为物理页/实页/页框
- 虚拟地址空间中的页称为虚拟页/虚页
- 页表记录虚页调入主存时的位置

- ①. 页表

- 页表示例
- 页表项组成

- 有效位（装入位）：表示页面是否在主存
- 脏位（修改位）：表示页面是否被修改过
- 引用位（使用位）：配合替换算法设置

- 缺页处理过程

- 调用缺页异常处理程序
- 从磁盘调入空闲物理页框
- 可能需要页面替换
- 更新页表

- 优缺点

- 优点：页面长度固定，页表简单，调入方便
- 缺点：最后一页零头浪费，处理/保护/共享不如段式方便

- ②. 地址转换

- 虚拟地址结构

- 高位：虚页号
- 低位：页内偏移地址

- 物理地址结构

- 高位：物理页号
- 低位：页内偏移地址

- 转换过程

- 通过页表基址寄存器找到页表首地址
- 根据虚页号找到页表项
- 若装入位为1，取出物理页号拼接地址
- 若装入位为0，触发缺页处理

- ③. 快表（TLB）

- 原理

- 将频繁访问的页表项存入高速缓冲器
- 命中时无需访问主存页表

- 实现

- 用SRAM实现
- 类似Cache，采用全相联或组相联映射
- TLB表项组成：页表表项内容+TLB标记

- 工作方式

- 全相联映射：TLB标记为虚拟页号
- 组相联映射：TLB标记为虚拟页号高位

- ④. 具有TLB和Cache的多级存储系统

- 系统结构

- TLB采用全相联方式
- Cache采用2路组相联方式

- 访问流程

- 先查TLB
- TLB缺失时查页表
- 完成地址转换后访问Cache

- 三种缺失情况

- TLB缺失：页表项不在TLB中
- Cache缺失：主存块不在Cache中
- Page缺失：页面不在主存中

- 缺失组合情况

- 最好情况：无缺失
- 最差情况：缺页异常，需访问磁盘

- 处理方式

- Cache缺失：硬件处理
- 缺页处理：软件（操作系统）处理
- TLB缺失：硬件或软件处理

### 3.6.3 段式虚拟存储器

- 基本概念

- 按程序的逻辑结构划分段
- 各段长度因程序而异

- 地址结构

- 虚拟地址分为两部分

- 段号
- 段内地址

- 地址变换机制

- 通过段表实现虚拟地址到实地址的变换
- 段表内容

- 段号
- 装入位
- 段起点
- 段长

- 访存过程

- ①. 拼接段表基地址与段号形成段表项
- ②. 检查装入位

- 1: 段在主存
- 0: 段不在主存

- ③. 计算实地址

- 段起始地址 + 段内地址

- 特点

- 对程序员不透明
- 与分页的区别

- 分页对程序员透明

- 优点

- 与程序自然分界对应
- 具有逻辑独立性
- 易于编译、管理、修改和保护
- 便于多道程序共享

- 缺点

- 段长度可变导致空间分配不便
- 容易产生段间碎片
- 空间利用率低

### 3.6.4 段页式虚拟存储器

- 基本概念

- 程序按逻辑结构分段
- 每段划分为固定大小的页
- 主存空间划分为大小相等的页
- 调入调出以页为基本交换单位

- 数据结构

- 每个程序对应一个段表
- 每段对应一个页表
- 段的长度必须是页长的整数倍
- 段的起点必须是某一页的起点

- 地址结构

- 虚地址组成

- 段号
- 段内页号
- 页内地址

- 地址转换过程

- 根据段号得到段表地址
- 从段表取出页表起始地址
- 与段内页号合成页表地址
- 从页表取出实页号
- 与页内地址拼接形成主存实地址

- 优点

- 兼具页式和段式虚拟存储器的优点
- 可以按段实现共享和保护

- 缺点

- 地址变换需要两次查表
- 系统开销较大

### 3.6.5 虚拟存储器与Cache 的比较

- 都有地址映射、替换算法、更新策略等问题
- 都依据局部性原理应用
