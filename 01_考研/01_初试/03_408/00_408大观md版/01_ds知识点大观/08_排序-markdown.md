# 第八章 排序
## 8.1   排序的基本概念
### 8.1.1   排序的定义
- 排序的定义
  - 重新排列表中的元素
  - 使元素满足按关键字有序的过程
  - 目的：便于查找

- 排序的输入输出
  - 输入
    - n个记录 R₁, R₂, ..., Rₙ
    - 对应关键字 k₁, k₂, ..., kₙ
  - 输出
    - 输入序列的一个重排 R'₁, R'₂, ..., R'ₙ
    - 满足 k'₁ ≤ k'₂ ≤ ... ≤ k'ₙ
## 8.2   插入排序
### 8.2.1   直接插入排序
- 基本思想
  - 将待排序表L[1…n]中的元素L(i)插入已有序的子序列L[1...i-1]
  - 操作步骤
    - 1)查找出L(i)在L[1...i-1]中的插入位置k
    - 2)将L[k….i-1]中的所有元素依次后移一个位置
    - 3)将L(i)复制到L(k)
  - 初始L[1]视为已排好序的子序列
  - 执行n-1次得到有序表
- 代码实现
  - void InsertSort(ElemType A[],int n)
    - 使用哨兵A[0]
    - 从A[2]开始插入
    - 从后往前比较并移动元素
- 性能分析
  - 空间效率
    - 使用常数个辅助单元
    - 空间复杂度为O(1)
  - 时间效率
    - 最好情况
      - 表中元素已经有序
      - 时间复杂度为O(n)
    - 最坏情况
      - 表中元素逆序
      - 时间复杂度为O(n²)
    - 平均情况
      - 比较次数和移动次数约为n²/4
      - 时间复杂度为O(n²)
  - 稳定性
    - 稳定的排序算法
    - 相同元素相对位置不变化
  - 适用性
    - 适用于顺序存储和链式存储的线性表
    - 链式存储时无须移动元素
### 8.2.2   折半插入排序
- 算法改进思路
  - 从直接插入排序中分离比较和移动操作
  - 先折半查找确定插入位置
  - 再统一移动元素
- 算法特点
  - 适用于顺序存储的线性表
  - 使用折半查找确定插入位置
- 算法代码
  - void InsertSort(ElemType A[],int n)
    - 初始化变量i,j,low,high,mid
    - for循环(i从2到n)
      - A[0]=A[i]（暂存待插入元素）
      - low=1,high=i-1（设置查找范围）
      - while循环（折半查找）
        - mid=(low+high)/2
        - if(A[mid]>A[0])查找左半子表
        - else查找右半子表
      - for循环（后移元素）
        - j从i-1到high+1
        - A[j+1]=A[j]
      - 插入操作A[high+1]=A[0]
- 算法分析
  - 时间复杂度
    - 比较次数约为O(nlog₂n)
    - 移动次数仍为O(n²)
    - 总体时间复杂度O(n²)
  - 稳定性
    - 是稳定的排序算法
  - 适用性
    - 仅适用于顺序存储的线性表
- 性能特点
  - 减少了比较次数
  - 移动次数与初始状态有关
  - 对数据量不大的排序表性能较好
### 8.2.3   希尔排序
- 基本概念
  - 基于直接插入排序改进
  - 又称缩小增量排序
- 特点
  - 适用于基本有序的排序表
  - 适用于数据量不大的排序表
- 算法思想
  - 将待排序表分割成若干子表
    - 子表形式：L[i,i+d,i+2d,...,i+kd]
  - 对各个子表进行直接插入排序
  - 当整体基本有序时，再进行一次直接插入排序
- 排序过程
  - 取增量d₁<n
  - 将记录分成d₁组
    - 同组记录距离为d₁的倍数
  - 对各组进行直接插入排序
  - 取更小增量d₂<d₁重复上述过程
  - 最终增量dₜ=1时进行最后一次排序
- 性能分析
  - 空间复杂度
    - O(1)
    - 仅使用常数个辅助单元
  - 时间复杂度
    - 一般情况：约O(n¹.³)
    - 最坏情况：O(n²)
  - 稳定性
    - 不稳定
    - 可能改变相同关键字的相对次序
  - 适用性
    - 仅适用于顺序存储的线性表
## 8.3   交换排序
### 8.3.1   冒泡排序
- 冒泡排序
  - 基本思想
    - 从后往前(或从前往后)两两比较相邻元素的值
    - 若为逆序(A[i-1]>A[i])则交换它们
    - 直到序列比较完
  - 过程描述
    - 第一趟冒泡
      - 结果是将最小元素交换到待排序列的第一个位置
      - 或最大元素交换到最后一个位置
    - 后续趟次
      - 前趟确定的最小元素不再参与比较
      - 每趟结果是把序列中的最小/最大元素放到最终位置
    - 最多需要n-1趟冒泡
  - 算法代码
    ```c
    void BubbleSort(ElemType A[], int n){
      for(int i=0; i<n-1; i++){
        bool flag = false;
        for(int j=n-1; j>i; j--)
          if(A[j-1]>A[j]){
            swap(A[j-1], A[j]);
            flag = true;
          }
        if(!flag) return;
      }
    }
    ```
  - 性能分析
    - 空间效率
      - 仅使用常数个辅助单元
      - 空间复杂度O(1)
    - 时间效率
      - 最好情况(初始有序)
        - 比较次数n-1
        - 移动次数0
        - 时间复杂度O(n)
      - 最坏情况(初始逆序)
        - 需要n-1趟排序
        - 每趟n-i次比较
        - 每次比较移动3次
        - 时间复杂度O(n²)
      - 平均时间复杂度O(n²)
    - 稳定性
      - 稳定排序算法
      - 相等元素不会交换
    - 适用性
      - 适用于顺序存储和链式存储的线性表
  - 注意事项
    - 产生的有序子序列是全局有序的
    - 每趟排序都会将一个元素放置到最终位置
### 8.3.2   快速排序
- 基本思想
  - 任取一个元素pivot作为枢轴
  - 将待排序表划分为两部分
    - L[1…k-1]中的所有元素小于pivot
    - L[k+1…n]中的所有元素大于或等于pivot
  - pivot放在最终位置L(k)上
  - 递归地对两个子表重复上述过程
- 一趟快速排序过程
  - 交替搜索和交换的过程
- 算法实现
  - QuickSort函数
    - 递归跳出条件:low<high
    - Partition操作划分表
    - 递归排序两个子表
  - Partition函数
    - 一趟划分
    - 将第一个元素设为枢轴
    - 循环跳出条件:low<high
    - 将比枢轴小的元素移动到左端
    - 将比枢轴大的元素移动到右端
    - 枢轴元素存放到最终位置
    - 返回存放枢轴的最终位置
- 性能分析
  - 空间效率
    - 递归工作栈
      - 最好情况:O(log₂n)
      - 最坏情况:O(n)
      - 平均情况:O(log₂n)
  - 时间效率
    - 与划分是否对称有关
    - 最坏情况:O(n²)
      - 初始排序表基本有序或基本逆序
    - 提高效率的方法
      - 选取中分的枢轴元素
      - 随机选取枢轴元素
    - 最理想状态:O(nlog₂n)
    - 平均性能最优
  - 稳定性
    - 不稳定的排序算法
    - 相对位置可能发生变化
- 适用性
  - 仅适用于顺序存储的线性表


## 8.4   选择排序
### 8.4.1   简单选择排序
- 算法思想
  - 假设排序表为 L[1…n]
  - 第 i 趟排序从 L[i…n] 中选择关键字最小的元素与 L(i) 交换
  - 每趟排序确定一个元素的最终位置
  - 经过 n-1 趟排序使整个排序表有序
- 性能分析
  - 空间效率
    - 使用常数个辅助单元
    - 空间效率为 O(1)
  - 时间效率
    - 元素移动操作不超过 3(n-1) 次
      - 最好情况移动 0 次（表已有序）
    - 元素比较次数始终为 n(n-1)/2 次
    - 时间复杂度始终为 O(n²)
  - 稳定性
    - 不稳定排序算法
  - 适用性
    - 适用于顺序存储和链式存储的线性表
    - 适用于关键字较少的情况
### 8.4.2   堆排序
- 堆的定义
  - n个关键字序列L[1…n]称为堆，当且仅当满足以下条件之一：
    - ① L(i)≥L(2i) 且 L(i)≥L(2i+1)
    - ② L(i)≤L(2i) 且 L(i)≤L(2i+1) (1≤i≤⌊n/2⌋)
- 堆的性质与特点
  - 可视为一棵完全二叉树
  - 大根堆（大顶堆）
    - 满足条件①
    - 最大元素在根结点
    - 任意非根结点值≤其双亲结点值
  - 小根堆（小顶堆）
    - 满足条件②
    - 最小元素在根结点
- 堆的应用
  - 堆排序
  - 优先队列
- 堆排序思路
  - 步骤
    - ①. 将L[1…n]建成初始堆
    - ②. 输出堆顶元素
    - ③. 将堆底元素送入堆顶
    - ④. 调整堆使其保持堆的性质
    - ⑤. 重复2-4直到堆中只剩一个元素
  - 关键问题
    - 如何构造初始堆
    - 输出堆顶后如何调整剩余元素成新堆
- 初始建堆
  - 方法
    - 从后往前检查所有分支结点
    - 对不满足堆要求的子树进行调整
  - 过程
    - 对以第⌊n/2⌋个结点为根的子树筛选
    - 向前依次对各结点（⌊n/2⌋-1 ~ 1）为根的子树进行筛选
- 堆的删除操作及调整
  - 步骤
    - 输出堆顶元素
    - 将最后一个元素与堆顶交换
    - 向下筛选调整堆
- 建立大根堆的算法
  - BuildMaxHeap函数
    - 参数：数组A[], 长度len
    - 从i=len/2到1反复调整堆
  - HeadAdjust函数
    - 参数：数组A[], 根结点k, 长度len
    - 沿key较大的子结点向下筛选
- 堆的插入操作
  - 步骤
    - 新结点放在堆的末端
    - 对新结点向上执行调整操作
- 堆排序的应用
  - 海量数据中选出最小k个数
    - 建立大小为k的小顶堆
    - 读入剩余数，若大于堆顶则替换并调整
- 堆排序算法性能分析
  - 空间效率
    - 空间复杂度：O(1)
  - 时间效率
    - 建堆时间：O(n)
    - 调整时间：O(h)
    - 总时间复杂度：O(nlog₂n)
  - 稳定性
    - 不稳定排序算法
  - 适用性
    - 仅适用于顺序存储的线性表
## 8.5   归并排序、基数排序和计数排序
### 8.5.1  归并排序
- 基本思想
  - 将两个或两个以上的有序表合并成一个新的有序表
  - 初始视为n个长度为1的有序子表
  - 两两归并，直到合并成一个长度为n的有序表
- Merge()函数
  - 功能：将相邻的两个有序表归并为一个有序表
  - 过程
    - 将两段有序表复制到辅助数组B
    - 比较B中两段的记录，将较小者放入A
    - 将剩余部分直接复制到A
  - 算法实现
    - ElemType *B=(ElemType*)malloc((n+1)*sizeof(ElemType))
    - void Merge(ElemType A[],int low,int mid,int high)
- 一趟归并排序
  - 调用[n/2h]次Merge()
  - 将长度为h的有序段两两归并为长度为2h的有序段
  - 共需进行[log₂n]趟
- 递归形式
  - 基于分治法
  - 分解
    - 将表分成各含n/2个元素的子表
    - 递归排序子表
  - 合并
    - 合并两个已排序的子表
  - 算法实现
    - void MergeSort(ElemType A[],int low,int high)
      - if(low<high)
        - int mid=(low+high)/2
        - MergeSort(A,low,mid)
        - MergeSort(A,mid+1,high)
        - Merge(A,low,mid,high)
- 性能分析
  - 空间效率
    - 辅助空间为n个单元
    - 空间复杂度O(n)
  - 时间效率
    - 每趟归并O(n)
    - 共[log₂n]趟
    - 时间复杂度O(nlog₂n)
  - 稳定性
    - 稳定的排序算法
  - 适用性
    - 适用于顺序存储和链式存储的线性表
### 8.5.2   基数排序
- 定义
  - 不基于比较和移动进行排序
  - 基于关键字各位的大小进行排序
  - 借助多关键字排序的思想对单逻辑关键字进行排序
- 关键字结构
  - 长度为n的线性表中每个结点a的关键字由d元组(k^(d-1),k^(d-2),...,k^1,k^0)组成
  - 满足0≤k^i≤r-1(0≤j<n,0≤i≤d-1)
  - k^(d-1)为最高位关键字
  - k^0为最低位关键字
- 多关键字排序方法
  - 最高位优先(MSD)法
    - 按关键字位权重递减逐层划分
    - 最后将所有子序列依次连接成有序序列
  - 最低位优先(LSD)法
    - 按关键字位权重递增依次排序
    - 最后形成有序序列
- LSD基数排序过程(r为基数)
  - 使用r个队列Q0,Q1,...,Q(r-1)
  - 对i=0,1,...,d-1依次进行分配和收集
    - 分配
      - 初始化队列为空
      - 依次考察每个结点a_j(j=0,1,...,n-1)
      - 若a_j的关键字k^i=k，则放入Q_k队列
    - 收集
      - 将各队列结点首尾相接
      - 组成新的线性表
- 性能分析
  - 空间效率
    - 空间复杂度:O(r)
    - 需要r个队列(队头指针和队尾指针)
  - 时间效率(2015)
    - 时间复杂度:O(d(n+r))
    - 进行d趟操作
      - 分配:O(n)
      - 收集:O(r)
    - 与序列初始状态无关
  - 稳定性
    - 稳定排序算法
    - 分配和收集从前往后进行
    - 不交换相同关键字的相对位置
  - 适用性
    - 适用于顺序存储和链式存储的线性表
## 8.6   各种内部排序算法的比较及应用
### 8.6.1   内部排序算法的比较
- 8.6.1 内部排序算法的比较
  - 比较因素
    - 时间复杂度
    - 空间复杂度
    - 稳定性
    - 适用性
    - 过程特征
  - 时间复杂度分析
    - O(n²)算法
      - 简单选择排序
        - 与初始状态无关
      - 直接插入排序
        - 最好情况O(n)
      - 冒泡排序
        - 最好情况O(n)
    - O(nlog₂n)算法
      - 堆排序
        - 线性时间建堆
      - 快速排序
        - 平均性能最优
        - 最坏情况O(n²)
      - 归并排序
        - 各种情况均为O(nlog₂n)
    - 希尔排序
      - 时间复杂度未精确确定
  - 空间复杂度分析
    - 常数空间算法
      - 简单选择排序
      - 插入排序
      - 冒泡排序
      - 希尔排序
      - 堆排序
    - 额外空间算法
      - 快速排序
        - 平均O(log₂n)
        - 最坏O(n)
      - 归并排序
        - O(n)辅助空间
  - 稳定性分析
    - 稳定排序算法
      - 插入排序
      - 冒泡排序
      - 归并排序
      - 基数排序
    - 不稳定排序算法
      - 简单选择排序
      - 快速排序
      - 希尔排序
      - 堆排序
  - 适用性分析
    - 仅顺序存储适用
      - 折半插入排序
      - 希尔排序
      - 快速排序
      - 堆排序
    - 顺序/链式存储均可
      - 直接插入排序
      - 冒泡排序
      - 简单选择排序
      - 归并排序
      - 基数排序
  - 过程特征分析
    - 每趟产生极值
      - 冒泡排序
      - 简单选择排序
      - 堆排序
    - 确定元素最终位置
      - 快速排序
### 8.6.2   内部排序算法的应用
- 选取排序算法需要考虑的因素
  - 待排序的元素个数n
  - 待排序的元素的初始状态
  - 关键字的结构及其分布情况
  - 稳定性的要求
  - 存储结构及辅助空间的大小限制
- 排序算法小结
  - 若n较小
    - 可采用直接插入排序或简单选择排序
    - 记录本身信息量较大时，用简单选择排序较好
  - 若n较大
    - 应采用时间复杂度为O(nlog₂n)的排序算法
      - 快速排序
      - 堆排序
      - 归并排序
    - 关键字随机分布时，快速排序最佳
    - 堆排序特点
      - 辅助空间少于快速排序
      - 不会出现快速排序的最坏情况
      - 不稳定
    - 要求稳定且O(nlog₂n)时选用归并排序
  - 若初始状态基本有序
    - 选用直接插入排序
    - 或冒泡排序
  - 基于比较的排序算法特点
    - 每次比较后仅两种可能转移
    - 可用二叉树描述比较判定过程
    - 随机分布时至少需要O(nlog₂n)时间
  - 若n很大且关键字位数较少
    - 采用基数排序较好
  - 记录本身信息量较大时
    - 用链表作为存储结构
    - 避免大量时间移动记录
## 8.7   外部排序
### 8.7.1   外部排序的基本概念
- 内部排序
  - 定义：排序算法在内存中进行
- 外部排序
  - 应用场景
    - 对大文件进行排序
    - 文件记录过多无法全部放入内存
  - 实现方式
    - 将记录存储在外存上
    - 分批调入内存进行排序
  - 特点
    - 需要多次内存和外存交换数据
### 8.7.2   外部排序的方法
- 文件存储与访问
  - 按块存储在磁盘上
  - 操作系统按块读/写
  - 时间代价主要考虑I/O次数
- 外部排序算法
  - 采用归并排序算法
  - 两个阶段
    - 阶段1：生成初始归并段
      - 根据内存缓冲区大小分块
      - 读入内存进行内部排序
      - 写回外存形成有序子文件（归并段/顺串）
    - 阶段2：逐趟归并
      - 归并段由小到大
      - 直至整个文件有序
- 时间分析
  - 总时间=内部排序时间+外存读写时间+内部归并时间
  - 外存读写时间占主要部分
  - 减少I/O次数是关键
- 归并路数与趟数关系
  - 对r个初始归并段，k路归并
  - 归并趟数S=⌈logₖr⌉
  - 减少S的方法
    - 增大归并路数k
    - 减少初始归并段个数r
  - 目的：减少磁盘I/O次数，提高排序速度
### 8.7.3   多路平衡归并与败者树
- 增加归并路数k的影响
  - 优点
    - 减少归并趟数S
    - 减少I/O次数
  - 缺点
    - 增加内部归并时间
    - 选择最小元素需要k-1次比较
    - 总比较次数公式：S(n-1)(k-1)=[log₂r(n-1)(k-1)/「log₂k]
    - (k-1)/log₂k随k增长而增长
- 败者树的引入
  - 目的：消除k增大对内部归并的影响
  - 性质
    - 树形选择排序的变体
    - 完全二叉树
    - 叶结点：存放k个归并段当前比较元素
    - 内部结点：记忆左右子树的
### 8.7.4   置换-选择排序(生成初始归并段)
- 目的
  - 减少初始归并段个数r
  - 减少归并趟数S
- 公式
  - 归并段个数r=[n/C]
    - n: 总记录个数
    - C: 每个归并段长度
- 传统方法问题
  - 初始归并段长度相同
  - 依赖内存工作区大小
- 置换-选择算法
  - 产生更长初始归并段
- 算法步骤
  - 1) 从FI输入w个记录到工作区WA
  - 2) 从WA选出关键字最小记录(MINIMAX记录)
  - 3) 将MINIMAX记录输出到FO
  - 4) 若FI不空，输入下一记录到WA
  - 5) 从WA中选出比当前MINIMAX大的最小关键字记录作为新MINIMAX
  - 6) 重复3)~5)直到选不出新MINIMAX，输出归并段结束标志
  - 7) 重复2)~6)直到WA为空，得到全部初始归并段
### 8.7.5   最佳归并树
- 归并树分析
  - 叶结点表示初始归并段
    - 权值：归并段长度
    - 路径长度：参加归并的趟数
  - 非叶结点表示新归并段
  - 根结点表示最终归并段
  - WPL（带权路径长度）= 归并总读记录数

- 最佳归并树构建原则
  - 推广哈夫曼树到m叉树
  - 让记录数少的归并段最先归并
  - 记录数多的归并段最晚归并

- 严格k叉树构造规则
  - 需要添加虚段（长度为0）的情况：
    - 当初始归并段不足以构成严格k叉树时
    - 权为0的叶子应离树根最远

- 虚段数量判定公式
  - 设：
    - n₀：度为0的结点数（初始归并段）
    - n_k：度为k的结点数
    - n：总结点数
  - 关系式：
    - n = n_k + n₀
    - n = k×n_k + 1
  - 严格k叉树条件：
    - n₀ = (k-1)×n_k + 1
    - 推导得：n_k = (n₀-1)/(k-1)
  - 判定条件：
    - 若(n₀-1)%(k-1)=0：正好构造k叉树
    - 若(n₀-1)%(k-1)=u≠0：
      - 需增加1个内结点
      - 补充(k-u-1)个空归并段
