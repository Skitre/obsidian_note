# 第 7 章 输入/输出系统 
## 7.2   I/O 接 口
### 7.2.1   I/O接口的功能
- 地址译码和设备选择
  - CPU送来选择外设的地址码
  - 接口对地址进行译码
  - 产生设备选择信息
- 通信联络控制
  - 解决主机与外设时序配合问题
  - 协调不同工作速度的设备
  - 保证系统统一协调工作
- 数据缓冲
  - 设置数据缓冲寄存器
  - 暂存数据
  - 消除速度差异
- 信号格式转换
  - 电平转换
  - 并/串或串/并转换
  - 模/数或数/模转换
- 传送控制命令和状态信息
  - CPU通过命令寄存器发出启动命令
  - 外设反馈状态信息
### 7.2.2   I/O接口的基本结构 
- I/O接口通用结构
  - 主机侧连接
    - I/O总线
      - 连接内存
      - 连接CPU
  - 寄存器组成
    - 数据缓冲寄存器
      - 暂存数据信息
    - 状态寄存器
      - 记录接口和设备状态
    - 控制寄存器
      - 保存CPU控制信息
    - 状态/控制寄存器合并
      - 传送方向相反
      - 访问时间错开
- I/O接口功能
  - 数据线传输内容
    - 读/写数据
    - 状态信息
    - 控制信息
    - 中断类型号
  - 地址线传输内容
    - I/O接口寄存器地址
  - 控制线传输内容
    - 读/写控制信号
    - 中断请求/响应信号
    - 仲裁信号
    - 握手信号
  - I/O控制逻辑功能
    - 命令字译码
    - 控制信号传输
    - 数据收发
    - 状态收集
- I/O指令特性
  - 特权指令
  - 操作系统内核使用
  - 访问寄存器操作
### 7.2.3   I/O接口的类型
- 按数据传送方式(外设和接口一侧)
  - 并行接口
    - 一字节或一个字的所有位同时传送
  - 串行接口
    - 一位一位地有序传送
    - 接口要完成数据格式的转换
- 按主机访问I/O 设备的控制方式
  - 程序查询接口
  - 中断接口
  - DMA 接口
- 按功能选择的灵活性
  - 可编程接口
    - 通过编程改变接口功能
  - 不可编程接口
### 7.2.4    I/O端口及其编址 
- I/O端口的定义及相关特性
  - 定义: I/O接口电路中可被CPU直接访问的寄存器
  - 类型:
    - 数据端口
    - 状态端口
    - 控制端口
  - 访问方式:
    - 数据端口: 读/写
    - 状态端口: 只读
    - 控制端口: 只写
- I/O端口编址方式
  - 独立编址(I/O映射方式)
    - 特点:
      - 单独编址
      - I/O地址空间与主存地址空间独立
      - 需要专用I/O指令
    - 优点:
      - 地址线少
      - 译码简单
      - 寻址速度快
      - 程序清晰
    - 缺点:
      - I/O指令功能有限
      - 程序设计灵活性差
      - 控制信号复杂
  - 统一编址(存储器映射方式)
    - 特点:
      - 主存地址空间分给I/O端口
      - 同一地址空间
      - 使用访存指令访问I/O
    - 优点:
      - 访问灵活方便
      - 编址空间大
      - 保护机制统一
    - 缺点:
      - 占用主存空间
      - 译码电路复杂
      - 译码速度慢
## 7.3   I/O 方 式 
### 7.3.1    程序查询方式 
- 信息交换的控制
  - 直接由CPU执行程序实现
- 接口设置
  - 数据缓冲寄存器（数据端口）
  - 设备状态寄存器（状态端口）
- 操作流程
  - ①. 读取设备状态
  - ②. 根据状态决定操作
    - 数据传送或等待
- 工作流程
  - ①. CPU执行初始化程序，预置传送参数
  - ②. 向I/O接口发出命令字，启动I/O设备
  - ③. 从外设接口读取状态信息
  - ④. CPU查询设备状态，直到外设准备就绪
  - ⑤. 传送一次数据
  - ⑥. 修改地址和计数器参数
  - ⑦. 判断传送是否结束
    - 未结束转第3步
    - 计数器为0结束
- 查询方式分类
  - ①. 独占查询
    - CPU持续查询接口状态
    - 100%时间用于I/O操作
    - 外设和CPU完全串行工作
  - ②. 定时查询
    - CPU周期性查询接口状态
    - 条件满足才传送数据
    - 时间间隔与数据传输速率有关
- 优点
  - 设计简单
  - 硬件量少
- 缺点
  - CPU花费大量时间查询和等待
  - 一段时间内只能与一台外设交换信息
  - CPU与设备串行工作，效率低

### 7.3.2   程序中断方式 
- 基本概念
  - 定义
    - 计算机执行程序过程中出现急需处理的异常情况或特殊请求
    - CPU暂时中止现行程序，转去处理异常或请求
    - 处理完毕返回原程序断点处继续执行
  - 早期目的
    - 处理数据传送
  - 现代功能
    - 实现CPU与I/O设备并行工作
    - 处理硬件故障和软件错误
    - 实现人机交互
    - 实现多道程序、分时操作
    - 实时处理快速响应
    - 应用程序和操作系统切换（软中断）
    - 多处理器系统信息交流和任务切换
  - 思想
    - 当前进程启动外设并阻塞
    - CPU选择其他进程执行
    - 外设完成准备后发送中断请求
    - CPU执行中断服务程序完成数据传送
    - 返回原进程继续执行
- 中断响应过程
  - 中断隐指令
    - 硬件自动操作
    - 功能
      - 关中断
      - 保存断点
      - 引出中断服务程序
  - 中断向量
    - 向量中断
      - 中断类型号对应中断服务程序入口地址
      - 中断向量表存储所有中断向量
      - 通过中断类型号计算中断向量地址
      - 取出入口地址送入PC
    - 非向量中断
      - 软件查询法
- 中断处理过程
  - 流程
    - 关中断
    - 保存断点
    - 中断服务程序寻址
    - 保存现场和屏蔽字
    - 开中断
    - 执行中断服务程序
    - 关中断
    - 恢复现场和屏蔽字
    - 开中断、中断返回
  - 单重中断
    - 去掉开中断和关中断步骤
- 多重中断和中断屏蔽技术
  - 单重中断
    - CPU不响应新中断请求
  - 多重中断
    - CPU暂停当前中断服务程序处理新中断请求
    - 中断嵌套
  - 中断屏蔽技术
    - 中断屏蔽字寄存器
      - 1表示屏蔽
      - 0表示正常请求
    - 动态调整中断处理优先级
    - 不影响中断响应优先级
  - 实例分析
    - 中断屏蔽字设置
    - CPU执行程序轨迹


### 7.3.3   DMA 方式 
- 定义
  - 完全由硬件进行成组信息传送的控制方式
  - 外设与内存之间开辟"直接数据通路"
  - 信息传送不经过CPU

- 适用场景
  - 磁盘、显卡、声卡、网卡等高速设备
  - 大批量数据传送

- 特点
  - 主存和DMA接口有直接数据通路
  - 不必中断现行程序
  - I/O与主机并行工作
  - 程序和传送并行工作

- 详细特点
  - 主存与CPU脱钩
  - 主存地址确定、数据计数由硬件实现
  - 需开辟专用缓冲区
  - 传送速度快
  - 需要预处理和后处理

- DMA控制器组成
  - 主要功能
    - 接受DMA请求
    - 向CPU发出总线请求
    - 确定传送参数
    - 执行数据传送
    - 报告操作结束
  - 核心组件
    - 主存地址计数器
      - 存放交换数据的主存地址
      - 传送后地址自动加1
    - 传送长度计数器
      - 记录数据总长度
      - 传送后计数器减1
    - 数据缓冲寄存器
      - 暂存传送数据
    - DMA请求触发器
    - 控制/状态逻辑
    - 中断机构

- DMA传送方式
  - 停止CPU访存
    - 优点：控制简单
    - 缺点：CPU利用率低
  - 周期挪用
    - 特点
      - I/O优先级高于CPU
      - 单字传送方式
    - 优点：平衡效率
    - 缺点：需频繁申请总线
  - DMA与CPU交替访存
    - 将CPU周期分成两个时间片
    - 优点：高传送速率
    - 缺点：硬件复杂

- DMA传送过程
  - 预处理阶段
    - CPU初始化DMA控制器
    - 设置传送方向
    - 测试并启动设备
  - 数据传送阶段
    - 完全由DMA硬件控制
    - 以数据块为基本单位
  - 后处理阶段
    - DMA发送中断请求
    - CPU执行中断服务程序
    - 包括校验数据等操作

- DMA与中断方式的区别
  - 程序切换
    - 中断：需要保护和恢复现场
    - DMA：不中断现行程序
  - 响应时机
    - 中断：指令执行结束时
    - DMA：任意机器周期结束时
  - CPU干预
    - 中断：需要CPU干预
    - DMA：基本不需要CPU干预
  - 优先级
    - DMA请求高于中断请求
  - 应用范围
    - 中断：处理异常事件
    - DMA：限于大批数据传送
  - 传送方式
    - 中断：程序传送
    - DMA：硬件传送
