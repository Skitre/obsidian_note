# 第 6 章 总 线 
## 6.1   总线概述 
### 6.1.1    总线基本概念 
- 总线定义
  - 一组能为多个部件分时和共享的公共信息传送线路
  - 分时特点
    - 同一时刻只允许有一个部件向总线发送信息
  - 共享特点
    - 总线上可挂接多个部件
    - 多个部件可同时从总线上接收相同的信息
- 总线设备
  - 主设备
    - 发出总线请求且获得总线控制权的设备
  - 从设备
    - 被主设备访问的设备
    - 只能响应从主设备发来的各种总线命令
- 总线特性
  - 机械特性
    - 尺寸、形状
  - 电气特性
    - 传输方向
    - 有效的电平范围
  - 功能特性
    - 每根传输线的功能
  - 时间特性
    - 信号和时序的关系
### 6.12     总线的分类 
- 按功能层次分类
  - 片内总线
    - 芯片内部的总线
    - 用于CPU芯片内部各寄存器之间及寄存器与ALU的连接
  - 系统总线
    - 计算机系统内各功能部件之间相互连接的总线
    - 分类
      - 数据总线
        - 传输数据、指令和中断类型号等
        - 双向传输
        - 位数反映一次能传送的数据位数
      - 地址总线
        - 指出数据所在的主存单元或I/O端口地址
        - 单向传输
        - 位数反映最大寻址空间
      - 控制总线
        - 传输各种命令、反馈和定时信号
        - 典型信号包括：时钟、复位、总线请求/允许、中断请求/回答、存储器读/写、I/O读、I/O写、传输确认等
    - 注意
      - 数据通路和数据总线的区别
        - 数据通路：数据流经的路径
        - 数据总线：数据传输的媒介
  - I/O总线
    - 连接中低速I/O设备
    - 通过I/O接口与系统总线连接
    - 目的：将低速设备与高速总线分离
    - 常见类型：USB、PCI总线
  - 通信总线
    - 计算机系统之间或与其他系统之间传送信息
    - 也称外部总线
- 按时序控制方式分类
  - 同步总线
    - 统一时钟进行同步
    - 在规定时钟节拍内完成总线操作
  - 异步总线
    - 无统一时钟
    - 通过信号握手协调
    - 总线操作时序不固定
    - 异步总线默认一位初始位
- 按数据传输方式分类
  - 串行总线
    - 1条双向或2条单向数据线
    - 数据按比特位串行传输
    - 效率低于并行总线
    - 适合长距离通信
  - 并行总线
    - 多条双向数据线
    - 多比特位同时传输
    - 效率高于串行总线
    - 缺点
      - 各数据线传输特点可能存在差异
      - 数据线间相互干扰可能造成传输错误
    - 适合近距离通信
- 补充说明
  - 并行总线不一定总比串行总线快
  - 并行总线
    - 多个数据位同时传输
    - 需考虑数据协同性和线路干扰
    - 工作频率难以持续提高
  - 串行总线
    - 可通过提高工作频率来提升速度
    - 最终速度可超越并行总线
### 6.1.3    系统总线的结构 
- ①. 单总线结构
  - 定义：将CPU、主存、I/O设备都挂在一组总线上
  - 特点
    - 允许I/O设备之间、I/O设备与主存之间直接交换信息
    - CPU与主存、CPU与外设之间可以直接通过总线交换信息
    - 系统总线分类：地址总线、数据总线、控制总线
  - 优点
    - 结构简单
    - 成本低
    - 易于接入新的设备
  - 缺点
    - 带宽低
    - 负载重
    - 多个部件只能争用唯一的总线
    - 不支持并发传送操作
- ②. 双总线结构
  - 组成
    - 主存总线：用于CPU、主存和通道之间传送数据
    - I/O总线：用于多个外部设备与通道之间传送数据
  - 优点
    - 将低速I/O设备从单总线上分离出来
    - 实现存储器总线和I/O总线分离
  - 缺点
    - 需要增加通道等硬件设备
- ③. 三总线结构
  - 组成
    - 主存总线：用于CPU和内存之间传送地址、数据和控制信息
    - I/O总线：用于CPU和各类外设之间通信
    - DMA总线：用于内存和高速外设之间直接传送数据
  - 优点
    - 提高I/O设备性能
    - 更快响应命令
    - 提高系统吞吐量
  - 缺点
    - 任意时刻只能使用一种总线
    - 系统工作效率较低
### 6.1.5    总线的性能指标 
- 1) 总线时钟周期
  - 机器的时钟周期
  - 控制整个计算机的各个部件
- 2) 总线时钟频率
  - 时钟周期的倒数
- 3) 总线传输周期
  - 一次总线操作所需时间
  - 包含阶段：
    - 申请阶段
    - 寻址阶段
    - 传输阶段
    - 结束阶段
  - 由若干总线时钟周期构成
- 4) 总线工作频率
  - 总线上各种操作的频率
  - 总线周期的倒数
  - 计算公式：
    - 总线周期=N个时钟周期 → 总线工作频率=时钟频率/N
    - 一个时钟周期传送K次数据 → 总线工作频率=总线时钟频率×K
- 5) 总线宽度
  - 也称总线位宽
  - 同时传输的数据位数
  - 通常指数据总线的根数
- 6) 总线带宽
  - 单位时间内最多可传输数据的位数
  - 衡量单位：字节/秒(B/s)
  - 计算公式：总线带宽=总线工作频率×(总线宽度/8)
- 7) 总线复用
  - 信号线在不同时间传输不同信息
  - 优点：节省空间和成本
- 8) 信号线数
  - 地址总线+数据总线+控制总线总数
- 主要性能指标
  - 总线宽度
  - 总线工作频率
  - 总线带宽
  - 关系：总线带宽=总线宽度×总线工作频率

## 6.2   总线事务和定时
### 6.2.1    总线事务 
- 请求阶段
  - 主设备(CPU或DMA)发出总线传输请求
  - 获得总线控制权
- 仲裁阶段
  - 总线仲裁机构决定总线使用权授予
- 寻址阶段
  - 主设备给出从设备地址及命令
  - 启动从模块
- 传输阶段
  - 主模块和从模块进行数据交换
  - 可单向或双向进行数据传送
- 释放阶段
  - 主模块信息从总线撤除
  - 让出总线使用权
- 数据传送方式
  - 非突发传送方式
    - 每个传送周期先传送地址再传送数据
    - 每次只能传输一个字长的数据
  - 突发(猝发)传送方式
    - 连续成组数据传送
    - 寻址阶段发送首地址
    - 传输阶段传送多个连续单元数据
    - 每个时钟周期传送一个字长信息
    - 不释放总线直到全部数据传送完毕

### 6.2.2    总线定时 
- 定义
  - 总线在双方交换数据的过程中需要时间上配合关系的控制
  - 实质是一种协议或规则
- 定时方式
  - 同步定时方式
    - 定义
      - 采用统一的时钟信号协调发送和接收双方的传送定时关系
    - 特点
      - 优点
        - 传送速度快
        - 总线控制逻辑简单
      - 缺点
        - 主从设备属于强制性同步
        - 不能及时进行数据通信的有效性检验
      - 适用场景
        - 总线长度较短
        - 总线所接部件的存取时间比较接近
    - 同步串行通信方式
      - 特点
        - 收发双方时钟严格一致
        - 仅在数据块的头尾处添加开始和结束标记
        - 传输效率较高
        - 硬件设备复杂
  - 异步定时方式
    - 定义
      - 没有统一的时钟
      - 依靠传送双方相互制约的"握手"信号来实现定时控制
    - 特点
      - 优点
        - 可靠性高
        - 适应性强
        - 能检测通信错误
      - 缺点
        - 传输效率较低
        - 控制逻辑复杂
      - 实现方式
        - 不互锁方式
        - 半互锁方式
        - 全互锁方式
    - 异步串行通信方式
      - 特点
        - 收发双方时钟独立
        - 每个字符都需要起始位和停止位
        - 传输效率较低
        - 硬件设备简单
- 总线周期
  - 定义
    - 完成一次总线操作所需的时间
  - 组成
    - 申请分配阶段
    - 寻址阶段
    - 传输阶段
    - 结束阶段
- 总线标准
  - 常见标准
    - ISA
    - PCI
    - USB
    - I2C
  - 包含内容
    - 机械特性
    - 电气特性
    - 功能特性
    - 时间特性
