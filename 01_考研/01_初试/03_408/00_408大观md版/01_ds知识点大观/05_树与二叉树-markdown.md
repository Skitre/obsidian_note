# 第五章 树与二叉树
## 5.1树的基本概念
### 5.1.1树的定义
- 树是n(n≥0)个结点的有限集
  - 当n=0时，称为空树
- 任意一棵非空树应满足
  - 有且仅有一个特定的称为根的结点
  - 当n>1时
    - 其余结点可分为m(m>0)个互不相交的有限集T₁,T₂,…,Tm
      - 每个集合本身又是一棵树
      - 称为根的子树
- 树的定义是递归的
  - 树是一种递归的数据结构
- 树作为逻辑结构的特点
  - 分层结构
  - 特点
    - 树的根结点没有前驱
    - 除根结点外的所有结点有且只有一个前驱
    - 树中所有结点都可以有零个或多个后继
- 树的适用场景
  - 表示具有层次结构的数据
- 树的结构特点
  - 某个结点(除根结点外)最多只和上一层的一个结点(其父结点)有直接关系
  - 根结点没有直接上层结点
  - 在n个结点的树中有n-1条边
  - 每个结点与其下一层的零个或多个结点(其孩子结点)都有直接关系
### 5.1.2基本术语
- 1) 祖先、子孙、双亲、孩子、兄弟和堂兄弟
  - 祖先：从根到某结点路径上的所有其他结点
  - 子孙：某结点的后代结点
  - 双亲：路径上最接近的祖先结点
  - 孩子：某结点的直接后代
  - 兄弟：有相同双亲的结点
  - 堂兄弟：双亲在同一层的结点
- 2) 结点的层次、深度和高度
  - 层次：从根开始定义，根为第1层
  - 深度：结点所在的层次
  - 高度
    - 树的高度：树中结点的最大层数
    - 结点的高度：以该结点为根的子树的高度
- 3) 结点的度和树的度
  - 结点的度：结点的孩子个数
  - 树的度：树中结点的最大度数
- 4) 分支结点和叶结点
  - 分支结点：度大于0的结点（非终端结点）
  - 叶结点：度为0的结点（终端结点）
- 5) 有序树和无序树
  - 有序树：子树有固定次序，不能互换
  - 无序树：子树无固定次序
- 6) 路径和路径长度
  - 路径：两个结点之间的结点序列
  - 路径长度：路径上经过的边的个数
- 7) 森林
  - 定义：m(m≥0)棵互不相交的树的集合
  - 与树的关系
    - 删除树的根结点→森林
    - 给m棵独立树加根结点→树
### 5.1.3树的性质
- 树的基本性质
  - 1) 树的结点数n等于所有结点的度数之和加1
    - 结点的度是指该结点的孩子数量
    - 每个结点与其每个孩子都由唯一的边相连
    - 树中所有结点的度数之和等于树中的边数之和
    - 结点数n等于边数之和加1
  - 2) 度为m的树中第i层上至多有m^(i-1)个结点(i≥1)
    - 第1层至多有1个结点(根结点)
    - 第2层至多有m个结点
    - 第3层至多有m²个结点
    - 以此类推
    - 使用数学归纳法可推出第i层至多有m^(i-1)个结点
  - 3) 高度为h的m叉树至多有(m^h-1)/(m-1)个结点
    - 当各层结点数达到最大时
    - 树中至多有1+m+m²+…+m^(h-1)=(m^h-1)/(m-1)个结点
  - 4) 度为m、具有n个结点的树的最小高度h为[log_m(n(m-1)+1)]
    - 为使树的高度最小
    - 前h-1层中，每层的结点数都要达到最大
    - 前h-1层最多有(m^(h-1)-1)/(m-1)个结点
    - 前h层最多有(m^h-1)/(m-1)个结点
    - 因此(m^(h-1)-1)/(m-1)<n≤(m^h-1)/(m-1)
    - 解得h_min=[log_m(n(m-1)+1)]
  - 5) 度为m、具有n个结点的树的最大高度h为n-m+1
    - 树的度为m，因此至少有一个结点有m个孩子
    - 它们处于同一层
    - 为使树的高度最大，其他层可仅有一个结点
    - 最大高度(层数)为n-m+1
    - 由此可逆推出高度为h、度为m的树至少有h+m-1个结点
## 5.2二叉树的概念
### 5.2.1二叉树的定义及其主要特性
- ①. 二叉树的定义
  - 二叉树特点
    - 每个结点至多只有两棵子树
    - 子树有左右之分，次序不能任意颠倒
  - 递归定义
    - 空二叉树（n=0）
    - 由一个根结点和两个互不相交的左子树和右子树组成
  - 二叉树是有序树
    - 左右子树颠倒则成为不同的二叉树
    - 单子树也需区分左右
  - 二叉树的5种基本形态
    - 空二叉树
    - 只有根结点
    - 只有左子树
    - 左右子树都有
    - 只有右子树
  - 二叉树与度为2的有序树的区别
    - 二叉树可以为空，度为2的树至少有3个结点
    - 二叉树必须确定左右次序，有序树单孩子无需区分
- ②. 几种特殊的二叉树
  - 1) 满二叉树
    - 高度为h，有2^h-1个结点
    - 每层都含有最多结点
    - 叶结点集中在最下一层
    - 非叶结点度数均为2
    - 层序编号规则
      - 根结点编号为1
      - 自上而下，自左向右
      - 编号i的结点
        - 双亲为⌊i/2⌋
        - 左孩子为2i
        - 右孩子为2i+1
  - 2) 完全二叉树
    - 高度为h，有n个结点
    - 每个结点与高度为h的满二叉树中编号1~n的结点一一对应
  - 3) 二叉排序树
    - 左子树所有结点关键字小于根结点
    - 右子树所有结点关键字大于根结点
    - 左右子树也是二叉排序树
  - 4) 平衡二叉树
    - 任意结点左右子树高度差绝对值不超过1
  - 5) 正则二叉树
    - 每个分支结点都有2个孩子
    - 只有度为0或2的结点
- ③. 二叉树的性质
  - 1) 非空二叉树
    - 叶结点数=度为2的结点数+1（n0=n2+1）
  - 2) 非空二叉树的第k层最多有2^(k-1)个结点（k≥1）
  - 3) 高度为h的二叉树至多有2^h-1个结点（h≥1）
  - 4) 完全二叉树编号关系
    - 最后一个分支结点编号为⌊n/2⌋
    - 叶结点只可能在最后两层
    - 度为1的结点最多一个，且只有左孩子
    - 编号i的结点为叶结点或只有左孩子时，编号>i的结点均为叶结点
    - n为奇数：每个分支结点都有左右孩子
    - n为偶数：最大分支结点只有左孩子
    - i>1时，双亲结点编号为⌊i/2⌋
    - 有左右孩子时，左孩子为2i，右孩子为2i+1
    - 结点i所在层次为⌊log₂i⌋+1
  - 5) 具有n个结点的完全二叉树高度
    - ⌈log₂(n+1)⌉
    - ⌊log₂n⌋+1
### 5.2.2二叉树的存储结构
- ①. 顺序存储结构

  - 定义：用一组连续的存储单元依次自上而下、自左至右存储完全二叉树上的结点元素
  - 存储方式：将完全二叉树上编号为i的结点元素存储在一维数组下标为i-1的分量中
  - 适用情况
    - 完全二叉树和满二叉树采用顺序存储比较合适
    - 优点
      - 树中结点的序号可以唯一地反映结点之间的逻辑关系
      - 节省存储空间
      - 利用数组元素的下标值确定结点位置及关系
  - 一般二叉树的处理
    - 添加不存在的空结点与完全二叉树对照
    - 存储到一维数组相应分量中
    - 缺点：最坏情况下高度为h的单支树需要占据近2^h-1个存储单元

- ②. 链式存储结构

  - 采用原因：顺序存储的空间利用率较低
  - 基本结构
    - 数据域data
    - 左指针域lchild
    - 右指针域rchild
  - 结点结构描述
    - typedef struct BiTNode{  } BiTNode, *BiTree;  // 定义结构体类型 BiTNode 及其指针类型 BiTree
    - ElemType data;  // 数据域，存储当前节点的元素值  
    - struct BiTNode *lchild, *rchild;  // 左孩子指针和右孩子指针  
  - 扩展结构：可增加指向父结点的指针，变为三叉链表
  - 重要结论：在含有n个结点的二叉链表中，含有n+1个空链域
  - 应用：利用空链域组成线索链表
## 5.3二叉树的遍历和线索二叉树
### 5.3.1二叉树的遍历
- 定义
  - 按某条搜索路径访问树中每个结点
  - 每个结点被访问一次且仅一次
- 遍历目的
  - 将非线性结构排列成线性队列
- 遍历原则
  - 先遍历左子树再遍历右子树
- 常见遍历次序
  - 先序(NLR)
    - 若二叉树为空则不做操作
    - 否则：
      - 访问根结点
      - 先序遍历左子树
      - 先序遍历右子树
  - 中序(LNR)
    - 若二叉树为空则不做操作
    - 否则：
      - 中序遍历左子树
      - 访问根结点
      - 中序遍历右子树
  - 后序(LRN)
    - 若二叉树为空则不做操作
    - 否则：
      - 后序遍历左子树
      - 后序遍历右子树
      - 访问根结点
  - 层次遍历
    - 遍历方式
      - 自上而下、从左至右逐层访问
    - 实现方法
      - 借助队列实现
    - 算法步骤
      - 根结点入队
      - 队头结点出队并访问
      - 若有左孩子则左孩子入队
      - 若有右孩子则右孩子入队
      - 重复直至队列为空
    - 算法实现
      - InitQueue(Q); // 初始化一个队列 Q  
      - BiTree p; // 定义一个指向二叉树节点的指针 p  
      - EnQueue(Q, T); // 将根节点入队  
      - while(!IsEmpty(Q)){} // 当队列不为空时，进行循环处理  
      - DeQueue(Q, p); // 队列出队一个节点，并用 p 指向该节点  
      - visit(p); // 访问该节点（例如打印节点值等）  
      - if(p->lchild != NULL) EnQueue(Q, p->lchild); // 若该节点有左孩子，则将左孩子入队  
- 遍历算法特性
  - 时间复杂度：O(n)
  - 空间复杂度：最坏情况下O(n)  
- 由遍历序列构造二叉树
  - 基本前提
    - 已知中序序列+其他任意一种序列可唯一确定二叉树
  - (1) 由先序序列和中序序列构造
    - 构造原理
      - 先序第一个结点为根结点
      - 中序序列被根结点分割为左右子树
  - (2) 由后序序列和中序序列构造
    - 构造原理
      - 后序最后一个结点为根结点
      - 中序序列被根结点分割为左右子树
  - (3) 由层序序列和中序序列构造
    - 构造原理
      - 层序第一个结点为根结点
      - 中序序列被根结点分割为左右子树
  - 注意：先序、后序和层序的两两组合不能唯一确定二叉树
### 5.3.2线索二叉树
- ①. 线索二叉树的基本概念
  - 遍历二叉树将结点排列成线性序列
  - 传统二叉链表存储的局限性
    - 不能直接得到前驱或后继
    - 空指针数量分析
      - 叶结点：2个空指针
      - 度为1的结点：1个空指针
      - 空指针总数公式：2n₀ + n₁ = n + 1
  - 线索二叉树的引入目的
    - 利用空指针存储前驱/后继指针
    - 加快查找前驱和后继的速度
  - 线索二叉树的规定
    - 无左子树：lchild指向前驱
    - 无右子树：rchild指向后继
  - 线索二叉树的结点结构
    - 数据元素(data)
    - 左右孩子指针(lchild, rchild)
    - 线索标志(ltag, rtag)
  - 存储结构描述
    - ThreadNode结构体定义
    - 线索链表和线索二叉树的定义
- ②. 中序线索二叉树的构造
  - 线索化的实质
    - 遍历过程中修改空指针为线索
  - 中序线索化算法
    - 使用pre指针指向前驱结点
    - 处理当前结点p的左指针
    - 处理前驱结点pre的右指针
  - 中序线索化主过程
    - CreateInThread函数实现
    - 处理最后一个结点的特殊情况
  - 带头结点的中序线索二叉树
    - 添加头结点的好处
    - 双向线索链表的实现方式
- ③. 中序线索二叉树的遍历
  - 遍历原理
    - 利用隐含的前驱和后继信息
  - 关键算法
    - 求第一个结点(Firstnode)
    - 求后继结点(Nextnode)
    - 中序遍历实现(Inorder)
  - 扩展思考
    - 求最后一个结点
    - 求前驱结点
- ④. 先序线索二叉树和后序线索二叉树
  - 先序线索二叉树
    - 构造过程示例
    - 找后继结点的规则
      - 有左孩子：左孩子为后继
      - 无左有右孩子：右孩子为后继
      - 叶结点：右链域指示后继
  - 后序线索二叉树
    - 构造过程示例
    - 找后继结点的三种情况
      - 根结点：后继为空
      - 双亲的右孩子/无右子树的左孩子：后继为双亲
      - 双亲有右子树的左孩子：后继为右子树后序第一个结点
    - 存储结构要求
      - 需要三叉链表存储双亲信息
## 5.4树、森林
### 5.4.1树的存储结构
- 存储方式要求

  - 能唯一反映树中各结点之间的逻辑关系

- 常用存储结构

  - ①. 双亲表示法

    - 存储方式
      - 连续空间存储每个结点
      - 每个结点增设伪指针指示双亲位置
    - 特点
      - 根结点伪指针域为-1
      - 可以快速找到双亲结点
      - 找孩子需要遍历整个结构

  - ②. 孩子表示法

    - 存储方式
      - 每个结点的孩子构成单链表
      - n个头指针采用顺序存储结构
    - 特点
      - 寻找孩子操作方便
      - 寻找双亲需要遍历n个孩子链表

  - ③. 孩子兄弟表示法

    - 别名
      - 二叉树表示法
    - 存储结构
      - 二叉链表存储
      - 结点包含三部分
        - 结点值
        - 指向第一个孩子的指针
        - 指向下一个兄弟的指针
    - 优点
      - 方便树转二叉树
      - 易于查找孩子
    - 缺点
      - 查找双亲较麻烦
      - 可增设parent域解决
    - 存储结构描述
      - typedef struct CSNode{  } CSNode, *CSTree; // 定义结构体类型 CSNode 及其指针类型 CSTree（用于指向孩子兄弟表示法的树）
      - ElemType data; // 数据域，存储当前节点的元素值  
      - struct CSNode *firstchild, *nextsibling; // 第一个孩子指针和下一个兄弟节点指针  
### 5.4.2树、森林与二叉树的转换
- 存储结构
  - 二叉树和树都可以用二叉链表作为存储结构
  - 树的孩子兄弟表示法与二叉树的二叉链表表示法物理结构相同
- 树转换为二叉树
  - 规则
    - 每个结点的左指针指向它的第一个孩子
    - 右指针指向它在树中的相邻右兄弟（左孩子右兄弟规则）
    - 根结点没有兄弟，转换后的二叉树没有右子树
  - 画法
    - 在兄弟结点之间加一连线
    - 对每个结点，只保留它与第一个孩子的连线，抹掉与其他孩子的连线
    - 以树根为轴心，顺时针旋转45°
- 森林转换为二叉树
  - 规则
    - 先将森林中的每棵树转换为二叉树
    - 各棵树的根视为兄弟关系
    - 将第二棵树对应的二叉树当作第一棵二叉树根的右子树，以此类推
  - 画法
    - 将森林中的每棵树转换成相应的二叉树
    - 在每棵树的根之间加一根连线
    - 以第一棵树的根为轴心顺时针旋转45°
    - 或先在森林中每棵树的根之间加连线，再采用树转二叉树的方法
- 二叉树转换为森林
  - 规则
    - 若二叉树非空，则二叉树的根及其左子树为第一棵树的二叉树形式
    - 将根的右链断开
    - 二叉树根的右子树视为由除第一棵树外的森林转换后的二叉树
    - 重复直到只剩一棵没有右子树的二叉树
    - 将每棵二叉树依次转换成树
  - 特点
    - 二叉树转换为树或森林是唯一的
### 5.4.3树和森林的遍历
- ①. 树的遍历
  - 定义：树的遍历是指用某种方式访问树中的每个结点，且仅访问一次
  - 遍历方式：
    - 先根遍历
      - 规则：
        - 先访问根结点
        - 再依次遍历根结点的每棵子树，遍历子树时仍遵循先根后子树的规则
      - 特点：遍历序列与这棵树相应二叉树的先序序列相同
    - 后根遍历
      - 规则：
        - 先依次遍历根结点的每棵子树，遍历子树时仍遵循先子树后根的规则
        - 再访问根结点
      - 特点：遍历序列与这棵树相应二叉树的中序序列相同
    - 层次遍历
      - 特点：与二叉树的层次遍历思想基本相同
      - 规则：按层序依次访问各结点
- ②. 森林的遍历
  - 遍历方式：
    - 先序遍历森林
      - 规则：
        - 访问森林中第一棵树的根结点
        - 先序遍历第一棵树中根结点的子树森林
        - 先序遍历除去第一棵树之后剩余的树构成的森林
    - 中序遍历森林
      - 规则：
        - 中序遍历森林中第一棵树的根结点的子树森林
        - 访问第一棵树的根结点
        - 中序遍历除去第一棵树之后剩余的树构成的森林
  - 转换关系：
    - 当森林转换成二叉树时
      - 第一棵树的子树森林转换成左子树
      - 剩余树的森林转换成右子树
    - 特点：
      - 森林的先序和中序遍历即其对应二叉树的先序和中序遍历
## 5.5树与二叉树的应用
### 5.5.1哈夫曼树和哈夫曼编码
- ①. 哈夫曼树的定义
  - 相关概念
    - 结点的权：树中结点被赋予的表示某种意义的数值
    - 带权路径长度：从根到结点的路径长度与该结点权值的乘积
    - 树的带权路径长度(WPL)：所有叶结点带权路径长度之和
  - 定义
    - 在含有n个带权叶结点的二叉树中，WPL最小的二叉树称为哈夫曼树（最优二叉树）
  - 示例
    - 计算WPL的公式：Σ(wi×li)
- ②. 哈夫曼树的构造
  - 构造算法
    - 1) 将n个结点作为n棵单结点二叉树，构成森林F
    - 2) 选取F中两棵根权值最小的树作为新结点的左右子树，新结点权值为子树根权值之和
    - 3) 从F中删除选出的两棵树，加入新树
    - 4) 重复2)-3)直到F只剩一棵树
  - 特点
    - 1) 初始结点都成为叶结点，权值越小路径越长
    - 2) 共新建n-1个结点，总结点数2n-1
    - 3) 不存在度为1的结点
- ③. 哈夫曼编码
  - 编码类型
    - 固定长度编码：每个字符用相等长度二进制位表示
    - 可变长度编码：不同字符用不等长二进制位表示
  - 前缀编码
    - 定义：没有一个编码是另一个编码的前缀
    - 示例：0(A),10(B),110(C)是前缀编码
    - 反例：若增加11(D)，则11是110的前缀
  - 二叉树设计
    - 左分支表示0，右分支表示1
    - 从根到叶的路径标记序列作为字符编码
  - 哈夫曼编码构造
    - 将字符作为结点，权值为出现频度
    - 构造哈夫曼树
    - 路径分支标记作为字符编码
### 5.5.2并查集
- ①. 并查集的概念
  - 支持3种操作
    - Initial(S)
      - 将集合s中的每个元素初始化为只有一个单元素的子集合
    - Union(S,Root1,Root2)
      - 把集合s中的子集合Root2并入子集合Root1
      - 要求Root1和Root2互不相交
    - Find(S,x)
      - 查找集合s中单元素x所在的子集合
      - 返回该子集合的根结点
- ②. 并查集的存储结构
  - 通常用树的双亲表示作为存储结构
    - 每个子集合以一棵树表示
    - 所有表示子集合的树构成表示全集合的森林
    - 存放在双亲表示数组内
  - 存储特点
    - 数组元素的下标代表元素名
    - 根结点的下标代表子集合名
    - 根结点的双亲域为负数（可设置为该子集合元素数量的相反数）
- ③. 并查集的基本实现
  - 结构定义
    - #define SIZE 100
    - int UFSets[SIZE] //集合元素数组(双亲指针数组)
  - 主要运算实现
    - 初始化操作
    - Find操作
      - 在并查集s中查找并返回包含元素x的树的根
      - 时间复杂度：O(d)，d为树的深度
    - Union操作
      - 求两个不相交子集合的并集
      - 时间复杂度：O(1)
- ④. 并查集实现的优化
  - 优化原因
    - 极端情况下，n个元素构成的集合树深度为n
    - Find操作最坏时间复杂度为O(n)
  - 改进方法
    - Union操作前先判别子集成员数量
    - 令成员少的根指向成员多的根（小树合并到大树）
    - 根结点的绝对值保存集合树中的成员数量
  - 改进后的Union操作
    - 集合树深度不超过⌊log₂n⌋+1
  - Find操作的路径压缩优化
    - 将从根到元素x路径上的所有元素都变成根的孩子
    - 集合树深度不超过O(α(n))
    - α(n)增长极其缓慢，通常α(n)≤4
